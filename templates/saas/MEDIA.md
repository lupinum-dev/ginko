# Media

Images and other media in this template, with their source and license. The code is MIT (see LICENSE); media keep
their own license. People are shown with their initials, never with stock photos of faces. This template uses no
photos.

## Made for this template

| File | What | License |
|---|---|---|
| `public/media/rota.svg` | a neutral drawing of a week's shift plan (rows for people, blocks for shifts, one open shift), with no text and no real interface: a placeholder for a screenshot of your product | MIT, like the code |
| `public/logos/care-home-one.svg`, `care-home-two.svg`, `clinic-three.svg`, `care-home-four.svg` | wordmarks of fictional care homes and a clinic (Musterstadt, Beispieltal), no real organisations | MIT, like the code |
| `.github/screenshots/home-light.png`, `home-dark.png` | screenshots of this template | MIT, like the code |

The share cards (1200 × 630) are generated by the site (nuxt-og-image). Inter is under the
[SIL Open Font License](https://openfontlicense.org).

When you add an image, put it in `public/media/`, give it alt text in every language file that shows it, and add a
row here. Replace the drawing on the home page with a real screenshot of your product: visitors want to see what they
will use.
