## Start here

This site is ready to run. Make it yours in three steps:

1. Write your own texts. They are Markdown files in `content/`; this page is `content/home.md`.
2. Set the name in `ginko.config.ts` and the menu in `app/app.config.ts`.
3. Pick your colour and fonts in `app/assets/css/main.css`.

The README of the project explains each step.
