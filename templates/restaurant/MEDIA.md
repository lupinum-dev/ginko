## Photo slots

Every place where the template shows a photo, with the ratio the page crops it to (`object-cover`, so nothing jumps
while it loads). A slot without a photo shows a complete layout, not an empty frame.

| Slot | File | Ratio on the page |
|---|---|---|
| Home hero | `content/home.md` → `image` | 16:9 |
| A free page (About) | `content/pages/<n>.<name>.md` → `image` | 16:9 |
| An event (card and page) | `content/events/<n>.<name>.md` → `image` | 3:2 card, 16:9 page |
| Gallery (page; the first three on the home page) | `content/gallery.md` → `images` | each photo keeps its own ratio (justified rows) |

Every photo needs alt text in each language: the main file has `src` and `alt`, a translation (`gallery.de.md`) only
`alt`, in the same order.
