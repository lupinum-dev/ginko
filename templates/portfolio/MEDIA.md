The share cards (1200 × 630) are generated by the site (nuxt-og-image). Inter and Instrument Serif are under the
[SIL Open Font License](https://openfontlicense.org).

When you add a photo, put it in `public/media/`, give it a description (`alt`) in every language file that shows it,
and add a row here. Keep each file at about 200 kB or less (1600 px on the long side is enough): phones with a sharp
screen may load the original file, so its size counts for how fast the first screen shows.
