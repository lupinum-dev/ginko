### Added

- `monitors.pause()` and `monitors.resume()` stop and restart the checks of a monitor, for example during maintenance. See [Monitors]($docs.monitors).
- `checks.list()` takes `ok: false` to return failed checks only.

### Fixed

- `checks.list()` read a `Date` in `since` as local time on servers outside UTC. It is now read as UTC, as documented.
- `webhooks.verify()` accepts a `Buffer` body as well as a string.
