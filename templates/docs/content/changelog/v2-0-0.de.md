Eine neue Hauptversion mit Änderungen, die bestehenden Code brechen. Die Anleitung [Upgrading to 2.0]($docs.upgrading-to-v2) (auf Englisch) zeigt jede Änderung mit dem Code vorher und nachher.

### Geändert

- Das Paket heißt jetzt `@orbit-example/sdk` (vorher `orbit-sdk`).
- Ein Client-Objekt: `new Orbit({ apiKey })` mit `orbit.monitors`, `orbit.incidents`, `orbit.checks` und `orbit.webhooks`.
- Listen nutzen Cursor (`limit`, `cursor`) statt Seitennummern, und `for await` liest alle Seiten. Siehe [Paginierung]($docs.pagination).
- Jeder Fehler ist ein `OrbitError` mit einem `code`. Siehe [Fehlercodes]($docs.error-codes).
- Nur noch Node.js 22 oder neuer und ES-Module.

### Neu

- Wiederholungen bei vorübergehenden Fehlern, standardmäßig zwei (`maxRetries`). Siehe [Fehler und Wiederholungen]($docs.errors-and-retries).
- Ein `Idempotency-Key` bei jedem `create()`, damit eine Wiederholung nie einen zweiten Monitor anlegt.
