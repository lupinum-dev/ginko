The last minor version of 1.x. It gets security fixes until 28 February 2027.

### Added

- `closeIncident(id, { note })` stores a note with the resolved incident.

### Fixed

- A `503` answer without a `Retry-After` header no longer throws a `TypeError`; it throws `OrbitHttpError` as documented.

### Deprecated

- `page` and `perPage` in list methods. 2.0 replaces them with cursors.
