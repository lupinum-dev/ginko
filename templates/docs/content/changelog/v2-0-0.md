A new major version with breaking changes. [Upgrading to 2.0]($docs.upgrading-to-v2) shows each change with the code before and after.

### Changed

- The package is now `@orbit-example/sdk` (was `orbit-sdk`).
- One client object: `new Orbit({ apiKey })` with `orbit.monitors`, `orbit.incidents`, `orbit.checks` and `orbit.webhooks`.
- Lists use cursors (`limit`, `cursor`) instead of page numbers, and `for await` reads every page. See [Pagination]($docs.pagination).
- Every error is an `OrbitError` with a `code`. See [Error codes]($docs.error-codes).
- Node.js 22 or newer and ES modules only.

### Added

- Retries for temporary errors, two by default (`maxRetries`). See [Errors and retries]($docs.errors-and-retries).
- An `Idempotency-Key` on every `create()`, so a retry never creates a second monitor.
