Die letzte Nebenversion von 1.x. Sie bekommt Sicherheitskorrekturen bis zum 28. Februar 2027.

### Neu

- `closeIncident(id, { note })` speichert eine Notiz zum behobenen Vorfall.

### Behoben

- Eine `503`-Antwort ohne `Retry-After`-Header wirft keinen `TypeError` mehr, sondern wie beschrieben einen `OrbitHttpError`.

### Veraltet

- `page` und `perPage` in Listenmethoden. 2.0 ersetzt sie durch Cursor.
