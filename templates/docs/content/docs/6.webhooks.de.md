Ein Webhook ist eine Anfrage, die Orbit an deinen Server schickt, wenn etwas passiert. So musst du die API nicht jede Minute fragen. Nutze ihn, um in einen Chat zu schreiben, die Bereitschaft zu alarmieren oder auf deiner Statusseite einen Hinweis zu zeigen.

## Ereignisse

| Ereignis | Kommt, wenn |
|---|---|
| `incident.opened` | ein Monitor zwei Prüfungen hintereinander nicht besteht und Orbit einen Vorfall eröffnet |
| `incident.resolved` | der Monitor wieder antwortet oder jemand den Vorfall als behoben markiert |
| `monitor.paused` | ein Monitor pausiert wird |
| `monitor.resumed` | ein pausierter Monitor wieder startet |

## Endpunkt hinzufügen

Öffne im Orbit-Dashboard **Settings > Webhooks**, wähle **Add endpoint**, trag die Adresse deines Servers ein und wähle die Ereignisse. Orbit zeigt ein Signaturgeheimnis, das mit `whsec_` beginnt. Bewahre es wie einen API-Schlüssel auf, zum Beispiel als `ORBIT_WEBHOOK_SECRET`.

## Signatur prüfen

Jeder kann eine Anfrage an deinen Endpunkt schicken. Jeder Webhook von Orbit trägt einen `orbit-signature`-Header, der mit deinem Signaturgeheimnis entstanden ist; `orbit.webhooks.verify()` prüft ihn und gibt das Ereignis zurück. Übergib den Body genau so, wie er ankam, als Text und nicht als geparstes JSON.

```ts [server/api/orbit-webhook.post.ts]
import { Orbit, OrbitError } from '@orbit-example/sdk'

const orbit = new Orbit()

export default defineEventHandler(async (event) => {
  const body = await readRawBody(event, 'utf8')
  const signature = getHeader(event, 'orbit-signature')
  try {
    const hook = orbit.webhooks.verify(body ?? '', signature ?? '', process.env.ORBIT_WEBHOOK_SECRET!)
    if (hook.type === 'incident.opened') await notifyTeam(hook.data.monitorId, hook.data.cause)
    return { ok: true }
  } catch (error) {
    if (error instanceof OrbitError && error.code === 'invalid_signature') throw createError({ statusCode: 400 })
    throw error
  }
})
```

`verify()` lehnt außerdem Webhooks ab, die älter als fünf Minuten sind. So lässt sich eine mitgeschnittene Anfrage nicht später noch einmal senden.

## Schnell antworten

Antworte innerhalb von 10 Sekunden mit einem beliebigen 2xx-Status. Bekommt Orbit einen anderen Status oder keine Antwort, sendet es den Webhook erneut: nach 1 Minute, 10 Minuten, 1 Stunde und 6 Stunden, danach nicht mehr. Dasselbe Ereignis kann also mehr als einmal ankommen; `hook.id` ist jedes Mal gleich, überspring also eine id, die du schon kennst.

## Ausprobieren

Im Dashboard schickt **Send test event** ein `incident.opened`-Ereignis für einen Testmonitor an deinen Endpunkt. Um einen Server auf deinem eigenen Rechner zu erreichen, nutze einen Tunnel wie `cloudflared` oder `ngrok`.
