## new Orbit(options?)

```ts
import { Orbit } from '@orbit-example/sdk'

const orbit = new Orbit({ apiKey: process.env.ORBIT_API_KEY, timeout: 10_000 })
```

Legt einen Client an. Er hält keine Verbindung offen; ein Client pro App genügt und kostet nichts, solange er nichts tut. Jede Option ist optional.

| Option | Typ | Standard | Wirkung |
|---|---|---|---|
| `apiKey` | `string` | `process.env.ORBIT_API_KEY` | Der API-Schlüssel. Ohne ihn wirft der Konstruktor `missing_api_key`. Siehe [Authentifizierung]($docs.authentication). |
| `baseUrl` | `string` | `'https://api.orbit.example.com/v2'` | Die Adresse der API. Ändere sie nur für einen Proxy oder einen Mock-Server in Tests. |
| `timeout` | `number` | `30_000` | Millisekunden, die ein Versuch auf eine Antwort wartet, bevor er mit `timeout` scheitert. |
| `maxRetries` | `number` | `2` | Wiederholungen nach einem vorübergehenden Fehler. `0` schaltet sie ab. Siehe [Fehler und Wiederholungen]($docs.errors-and-retries). |
| `headers` | `Record<string, string>` | `{}` | Header für jede Anfrage, zum Beispiel ein Tracing-Header. |
| `fetch` | `typeof fetch` | `globalThis.fetch` | Das `fetch`, das der Client nutzt, zum Beispiel ein Mock in Tests. |

## Eigenschaften

| Eigenschaft | Typ | Was sie ist |
|---|---|---|
| `orbit.monitors` | `Monitors` | Monitore anlegen, lesen, ändern, pausieren und löschen. Siehe [Monitore]($docs.monitors). |
| `orbit.incidents` | `Incidents` | Vorfälle lesen und als behoben markieren. Siehe [Vorfälle und Prüfungen]($docs.incidents-and-checks). |
| `orbit.checks` | `Checks` | Das Ergebnis jeder Prüfung lesen. Siehe [Vorfälle und Prüfungen]($docs.incidents-and-checks). |
| `orbit.webhooks` | `Webhooks` | Eingehende Webhooks prüfen. Siehe [Webhooks]($docs.webhooks). |

## Optionen einer Anfrage

Jede Methode nimmt als letztes Argument die Optionen einer einzelnen Anfrage. Sie gelten nur für diese Anfrage und gehen den Optionen des Clients vor.

```ts
await orbit.monitors.get('mon_8f2k1x', { timeout: 5_000, maxRetries: 0 })
```

| Option | Typ | Wirkung |
|---|---|---|
| `timeout` | `number` | Millisekunden für diese Anfrage. |
| `maxRetries` | `number` | Wiederholungen für diese Anfrage. |
| `signal` | `AbortSignal` | Bricht die Anfrage ab; die Methode wirft dann den Grund des Signals. |
| `idempotencyKey` | `string` | Ein eigener Schlüssel statt des erzeugten (nur bei `create()`-Methoden). |

## Typen

Das Paket exportiert den Typ jeder Antwort, damit du ihn in deinem Code benennen kannst:

```ts
import type { Check, Incident, Monitor, MonitorStatus, Page } from '@orbit-example/sdk'
```
