---

Eine **Prüfung** (check) ist eine Anfrage, die Orbit an eine überwachte Adresse sendet. Ein **Vorfall** (incident) beginnt, wenn ein Monitor zwei Prüfungen hintereinander nicht besteht, und endet, wenn er wieder antwortet.

## Der Typ Incident

```ts
interface Incident {
  id: string                 // 'inc_3hq9we'
  monitorId: string
  status: 'open' | 'resolved'
  cause: string              // 'HTTP 503' oder 'Timeout after 30 s'
  openedAt: string           // ISO 8601, UTC
  resolvedAt: string | null
  note: string | null        // gesetzt von incidents.resolve()
}
```

## incidents.list()

```ts
list(params?: ListIncidents, options?: RequestOptions): PageRequest<Incident>
```

Gibt Vorfälle zurück, die neuesten zuerst.

| Parameter | Typ | Standard | |
|---|---|---|---|
| `monitorId` | `string` | alle Monitore | Nur Vorfälle dieses Monitors. |
| `status` | `'open' \| 'resolved'` | beide | Nur offene oder nur behobene Vorfälle. |
| `limit` | `number` | `20` | Einträge pro Seite, 1 bis 100. |
| `cursor` | `string` | – | `nextCursor` der vorigen Seite. |

## incidents.get()

```ts
get(id: string, options?: RequestOptions): Promise<Incident>
```

Gibt einen Vorfall zurück. Wirft `not_found`, wenn es keinen mit dieser id gibt.

## incidents.resolve()

```ts
resolve(id: string, params?: { note?: string }, options?: RequestOptions): Promise<Incident>
```

Markiert einen offenen Vorfall als behoben, etwa wenn du die Ursache kennst und die nächste Prüfung noch Minuten entfernt ist. `note` (höchstens 500 Zeichen) erscheint im Dashboard und im Webhook `incident.resolved`. Einen behobenen Vorfall erneut zu beheben wirft `conflict`.

## Der Typ Check

```ts
interface Check {
  id: string                 // 'chk_91mdzr'
  monitorId: string
  region: Region
  ok: boolean
  statusCode: number | null  // null, wenn keine Antwort kam
  durationMs: number
  checkedAt: string          // ISO 8601, UTC
}
```

## checks.list()

```ts
list(params: ListChecks, options?: RequestOptions): PageRequest<Check>
```

Gibt die Prüfungen eines Monitors zurück, die neuesten zuerst. Orbit bewahrt Prüfungen 30 Tage auf.

| Parameter | Typ | Standard | |
|---|---|---|---|
| `monitorId` | `string` | Pflicht | Der Monitor. |
| `since` | `Date \| string` | vor 24 Stunden | Nur Prüfungen ab diesem Zeitpunkt. Ein String ist eine Zeit nach ISO 8601; ein `Date` gilt als UTC. |
| `ok` | `boolean` | beide | `false` für nur fehlgeschlagene Prüfungen. |
| `limit` | `number` | `20` | Einträge pro Seite, 1 bis 100. |
| `cursor` | `string` | – | `nextCursor` der vorigen Seite. |
