## new Orbit(options?)

```ts
import { Orbit } from '@orbit-example/sdk'

const orbit = new Orbit({ apiKey: process.env.ORBIT_API_KEY, timeout: 10_000 })
```

Creates a client. It keeps no connection open, so one client per app is enough and costs nothing while idle. Every option is optional.

| Option | Type | Default | What it does |
|---|---|---|---|
| `apiKey` | `string` | `process.env.ORBIT_API_KEY` | The API key. Without one, the constructor throws `missing_api_key`. See [Authentication]($docs.authentication). |
| `baseUrl` | `string` | `'https://api.orbit.example.com/v2'` | The address of the API. Change it only for a proxy or a mock server in tests. |
| `timeout` | `number` | `30_000` | Milliseconds to wait for an answer before the attempt fails with `timeout`. |
| `maxRetries` | `number` | `2` | Retries after a temporary error. `0` turns retries off. See [Errors and retries]($docs.errors-and-retries). |
| `headers` | `Record<string, string>` | `{}` | Headers added to every request, for example a tracing header. |
| `fetch` | `typeof fetch` | `globalThis.fetch` | The `fetch` to use, for example a mock in tests. |

## Properties

| Property | Type | What it is |
|---|---|---|
| `orbit.monitors` | `Monitors` | Create, read, change, pause and delete monitors. See [Monitors]($docs.monitors). |
| `orbit.incidents` | `Incidents` | Read and resolve incidents. See [Incidents and checks]($docs.incidents-and-checks). |
| `orbit.checks` | `Checks` | Read the result of each check. See [Incidents and checks]($docs.incidents-and-checks). |
| `orbit.webhooks` | `Webhooks` | Check incoming webhooks. See [Webhooks]($docs.webhooks). |

## Request options

Every method takes the options of one request as its last argument. They win over the client’s options for that request only.

```ts
await orbit.monitors.get('mon_8f2k1x', { timeout: 5_000, maxRetries: 0 })
```

| Option | Type | What it does |
|---|---|---|
| `timeout` | `number` | Milliseconds for this request. |
| `maxRetries` | `number` | Retries for this request. |
| `signal` | `AbortSignal` | Cancels the request; the method then throws the signal’s reason. |
| `idempotencyKey` | `string` | Your own key instead of the generated one (`create()` methods only). |

## Types

The package exports the type of every answer, so you can name them in your code:

```ts
import type { Check, Incident, Monitor, MonitorStatus, Page } from '@orbit-example/sdk'
```
