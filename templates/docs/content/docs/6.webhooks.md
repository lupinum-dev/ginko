---
title: Webhooks
description: Receive an HTTP request when a monitor goes down or comes back, and check that Orbit sent it.
---

A webhook is a request Orbit sends to your server when something happens, so you do not have to ask the API every minute. Use it to post to a chat, page the person on call, or show a notice on your status page.

## Events

| Event | Sent when |
|---|---|
| `incident.opened` | a monitor fails two checks in a row and Orbit opens an incident |
| `incident.resolved` | the monitor answers again, or someone resolves the incident |
| `monitor.paused` | a monitor is paused |
| `monitor.resumed` | a paused monitor is resumed |

## Add an endpoint

In the Orbit dashboard, open **Settings > Webhooks**, choose **Add endpoint**, enter the address of your server and pick the events. Orbit shows a signing secret that starts with `whsec_`. Store it like an API key, for example as `ORBIT_WEBHOOK_SECRET`.

## Check the signature

Anyone can send a request to your endpoint. Each webhook from Orbit carries an `orbit-signature` header made with your signing secret; `orbit.webhooks.verify()` checks it and returns the event. Pass the body exactly as it arrived, as text, not parsed JSON.

```ts [server/api/orbit-webhook.post.ts]
import { Orbit, OrbitError } from '@orbit-example/sdk'

const orbit = new Orbit()

export default defineEventHandler(async (event) => {
  const body = await readRawBody(event, 'utf8')
  const signature = getHeader(event, 'orbit-signature')
  try {
    const hook = orbit.webhooks.verify(body ?? '', signature ?? '', process.env.ORBIT_WEBHOOK_SECRET!)
    if (hook.type === 'incident.opened') await notifyTeam(hook.data.monitorId, hook.data.cause)
    return { ok: true }
  } catch (error) {
    if (error instanceof OrbitError && error.code === 'invalid_signature') throw createError({ statusCode: 400 })
    throw error
  }
})
```

`verify()` also refuses a webhook older than five minutes, so a recorded request cannot be sent again later.

## Answer quickly

Answer with any 2xx status within 10 seconds. Orbit sends a webhook again when it gets another status or no answer: after 1 minute, 10 minutes, 1 hour and 6 hours, then it gives up. The same event can therefore arrive more than once; `hook.id` is the same each time, so skip an id you have seen.

## Try it

In the dashboard, **Send test event** sends an `incident.opened` event for a test monitor to your endpoint. To reach a server on your own computer, use a tunnel such as `cloudflared` or `ngrok`.
