Orbit SDK is the official TypeScript client for the [Orbit API](https://orbit.example.com). Orbit checks your websites and APIs from several regions, every 30 seconds to 15 minutes, and opens an incident when one stops answering. The SDK lets your own code do what the Orbit dashboard does: create and pause monitors, read incidents and check results, and receive webhooks.

## What the client does for you

- **Types for every request and answer.** Your editor knows that `monitor.status` is `'up'`, `'down'`, `'paused'` or `'pending'`.
- **Retries.** A request that fails because of the network, a timeout, rate limiting or a server error is sent again, up to two more times. See [Errors and retries]($docs.errors-and-retries).
- **Pagination.** Lists come in pages of up to 100 entries; `for await` reads all of them. See [Pagination]($docs.pagination).
- **Webhook checks.** `orbit.webhooks.verify()` proves that a webhook came from Orbit. See [Webhooks]($docs.webhooks).

## What you need

- Node.js 22 or newer, or another runtime with `fetch` (Deno, Bun, Cloudflare Workers).
- An Orbit account and an API key. See [Authentication]($docs.authentication).
- ES modules. The package has no CommonJS build.

::callout{type="warning" title="Keep the key on the server"}
An API key can delete every monitor of your account. Use the SDK in server code only, never in code that runs in the browser.
::
