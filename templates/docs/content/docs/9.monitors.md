A monitor is one address that Orbit checks at a fixed interval. All methods are on `orbit.monitors`.

## The Monitor type

```ts
interface Monitor {
  id: string                 // 'mon_8f2k1x'
  name: string
  url: string
  interval: 30 | 60 | 300 | 900  // seconds between checks
  regions: Region[]          // 'eu-central' | 'us-east' | 'ap-southeast'
  expectedStatus: number     // HTTP status that counts as up
  status: MonitorStatus      // 'pending' | 'up' | 'down' | 'paused'
  createdAt: string          // ISO 8601, UTC
  lastCheckedAt: string | null
}
```

## monitors.create()

```ts
create(params: CreateMonitor, options?: RequestOptions): Promise<Monitor>
```

Creates a monitor. The first check runs within one interval.

| Parameter | Type | Default | |
|---|---|---|---|
| `name` | `string` | required | Shown in the dashboard and in webhooks. At most 100 characters. |
| `url` | `string` | required | An `http` or `https` address. |
| `interval` | `30 \| 60 \| 300 \| 900` | `60` | Seconds between checks. |
| `regions` | `Region[]` | `['eu-central']` | Where Orbit checks from. More regions mean an incident opens only when most of them fail. |
| `expectedStatus` | `number` | `200` | The HTTP status that counts as up. |

Throws `conflict` when a monitor for the same `url` exists, and `validation_failed` for a wrong value.

## monitors.get()

```ts
get(id: string, options?: RequestOptions): Promise<Monitor>
```

Returns one monitor. Throws `not_found` when there is no monitor with this id.

## monitors.list()

```ts
list(params?: ListMonitors, options?: RequestOptions): PageRequest<Monitor>
```

Returns the monitors, newest first. Await it for one page, or use `for await` for all (see [Pagination]($docs.pagination)).

| Parameter | Type | Default | |
|---|---|---|---|
| `status` | `MonitorStatus` | all | Only monitors with this status. |
| `limit` | `number` | `20` | Entries per page, 1 to 100. |
| `cursor` | `string` | – | `nextCursor` of the page before. |

## monitors.update()

```ts
update(id: string, changes: UpdateMonitor, options?: RequestOptions): Promise<Monitor>
```

Changes `name`, `url`, `interval`, `regions` or `expectedStatus`. Fields you leave out stay as they are. Returns the changed monitor.

## monitors.pause()

```ts
pause(id: string, options?: RequestOptions): Promise<Monitor>
```

Stops the checks until you resume them, for example during maintenance. A paused monitor opens no incident. Pausing a paused monitor changes nothing. New in 2.1.

## monitors.resume()

```ts
resume(id: string, options?: RequestOptions): Promise<Monitor>
```

Starts the checks again; the status is `pending` until the next check. New in 2.1.

## monitors.delete()

```ts
delete(id: string, options?: RequestOptions): Promise<void>
```

Deletes the monitor with its checks and incidents. This cannot be undone. Throws `not_found` when the monitor is already gone.
