## Set up

:::steps
### Install the package

::code-group
```bash [npm]
npm install @orbit-example/sdk
```
```bash [pnpm]
pnpm add @orbit-example/sdk
```
::

### Set your API key

Create a key in the Orbit dashboard under **Settings > API keys** and put it in the environment of your server. For local work, a `.env` file is fine; keep it out of Git.

```bash [.env]
ORBIT_API_KEY=orb_test_4f9a2c7e1b
```

A key that starts with `orb_test_` works on test data only, so you can try everything without real monitors.

### Send your first request

```ts [check-shop.ts]
import { Orbit } from '@orbit-example/sdk'

const orbit = new Orbit({ apiKey: process.env.ORBIT_API_KEY })

const monitor = await orbit.monitors.create({
  name: 'Shop checkout',
  url: 'https://shop.example.com/checkout',
})

console.log(monitor.id, monitor.status) // mon_8f2k1x pending
```

Run it with `node --env-file=.env check-shop.ts`. Node.js 22.18 and newer run TypeScript files directly.
:::

## What happened

1. `new Orbit()` creates a client. It holds your key, the address of the API and the retry settings; create it once and use it everywhere. All options are in [Client options]($docs.client).
2. `orbit.monitors.create()` sends one request to the API and returns the new monitor. Orbit checks the address once a minute from the region `eu-central` until you change that.
3. The status is `pending` until the first check has run, usually within a minute. After that it is `up` or `down`.
