---
title: Upgrading to 2.0
description: What changed from Orbit SDK 1.x to 2.0 and how to update your code, step by step.
---

Version 2.0 has a new package name, one client object instead of separate functions, cursors instead of page numbers and one error class. Most apps need about half an hour to update. This page is in English only.

## 1. Change the package

The package moved from `orbit-sdk` to `@orbit-example/sdk`:

```bash
npm uninstall orbit-sdk
npm install @orbit-example/sdk
```

2.0 needs Node.js 22 or newer and ES modules. Replace `require()` with `import`.

## 2. Create one client

```ts
// 1.x
import { OrbitClient } from 'orbit-sdk'
const client = new OrbitClient('orb_live_…')

// 2.0
import { Orbit } from '@orbit-example/sdk'
const orbit = new Orbit({ apiKey: 'orb_live_…' })
```

## 3. Rename the methods

| 1.x | 2.0 |
|---|---|
| `client.listMonitors()` | `orbit.monitors.list()` |
| `client.getMonitor(id)` | `orbit.monitors.get(id)` |
| `client.addMonitor(url, name)` | `orbit.monitors.create({ url, name })` |
| `client.removeMonitor(id)` | `orbit.monitors.delete(id)` |
| `client.listIncidents(monitorId)` | `orbit.incidents.list({ monitorId })` |
| `client.closeIncident(id)` | `orbit.incidents.resolve(id)` |
| `verifyWebhook(body, signature, secret)` | `orbit.webhooks.verify(body, signature, secret)` |

## 4. Replace page numbers with cursors

1.x took `page` and `perPage`. 2.0 takes `limit` and `cursor`, and `for await` reads every page:

```ts
// 1.x
for (let page = 1; ; page++) {
  const monitors = await client.listMonitors({ page, perPage: 100 })
  if (!monitors.length) break
  // …
}

// 2.0
for await (const monitor of orbit.monitors.list({ limit: 100 })) {
  // …
}
```

See [Pagination]($docs.pagination).

## 5. Catch one error class

1.x threw `OrbitHttpError`, `OrbitTimeoutError` and `OrbitAuthError`. 2.0 throws `OrbitError` and puts the reason in `code`:

| 1.x | 2.0 |
|---|---|
| `OrbitAuthError` | `OrbitError` with `code` `unauthorized` or `forbidden` |
| `OrbitTimeoutError` | `OrbitError` with `code` `timeout` |
| `OrbitHttpError` with `status` 404 | `OrbitError` with `code` `not_found` |

1.x did not retry; 2.0 retries passing errors twice by default. If your code retried by itself, remove that loop or set `maxRetries: 0`. See [Errors and retries]($docs.errors-and-retries).
