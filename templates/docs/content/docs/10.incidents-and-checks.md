---
title: Incidents and checks
description: The methods of orbit.incidents and orbit.checks with their parameters, and the Incident and Check types.
---

A **check** is one request Orbit sends to a monitored address. An **incident** starts when a monitor fails two checks in a row and ends when it answers again.

## The Incident type

```ts
interface Incident {
  id: string                 // 'inc_3hq9we'
  monitorId: string
  status: 'open' | 'resolved'
  cause: string              // 'HTTP 503' or 'Timeout after 30 s'
  openedAt: string           // ISO 8601, UTC
  resolvedAt: string | null
  note: string | null        // set by incidents.resolve()
}
```

## incidents.list()

```ts
list(params?: ListIncidents, options?: RequestOptions): PageRequest<Incident>
```

Returns incidents, newest first.

| Parameter | Type | Default | |
|---|---|---|---|
| `monitorId` | `string` | all monitors | Only incidents of this monitor. |
| `status` | `'open' \| 'resolved'` | both | Only open or only resolved incidents. |
| `limit` | `number` | `20` | Entries per page, 1 to 100. |
| `cursor` | `string` | – | `nextCursor` of the page before. |

## incidents.get()

```ts
get(id: string, options?: RequestOptions): Promise<Incident>
```

Returns one incident. Throws `not_found` when there is none with this id.

## incidents.resolve()

```ts
resolve(id: string, params?: { note?: string }, options?: RequestOptions): Promise<Incident>
```

Marks an open incident as resolved, for example when you know the cause and the next check is minutes away. `note` (at most 500 characters) is shown in the dashboard and sent with the `incident.resolved` webhook. Resolving a resolved incident throws `conflict`.

## The Check type

```ts
interface Check {
  id: string                 // 'chk_91mdzr'
  monitorId: string
  region: Region
  ok: boolean
  statusCode: number | null  // null when there was no answer
  durationMs: number
  checkedAt: string          // ISO 8601, UTC
}
```

## checks.list()

```ts
list(params: ListChecks, options?: RequestOptions): PageRequest<Check>
```

Returns the checks of one monitor, newest first. Orbit keeps checks for 30 days.

| Parameter | Type | Default | |
|---|---|---|---|
| `monitorId` | `string` | required | The monitor. |
| `since` | `Date \| string` | 24 hours ago | Only checks from this time on. A string is an ISO 8601 time; a `Date` is read as UTC. |
| `ok` | `boolean` | both | `false` for failed checks only. |
| `limit` | `number` | `20` | Entries per page, 1 to 100. |
| `cursor` | `string` | – | `nextCursor` of the page before. |
