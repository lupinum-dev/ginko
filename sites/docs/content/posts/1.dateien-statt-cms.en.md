---
title: A blog from Markdown files
description: This blog is made of files in the repository. It uses the same path as the docs.
tags: [Files, Blog]
slug: blog-from-files
---

A post is a Markdown file in `content/posts/`. The fields are the frontmatter at the top: title, date, authors. The text follows below.

The blog is a brick like the docs. The site reads it with `useGinko`, and the addresses and the sitemap come from the bundle. There is no second path for content.

Authors are files too, in `content/authors/`. A post names them by id, for example `authors/lupinum`. The feed at `/en/blog/rss.xml` is built from the same files.
