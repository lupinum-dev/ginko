`@lupinum/ginko-components` gives Markdown text its building blocks: notices, tabs, cards, code groups, video, quizzes and more. Each group has a page that shows every component live, with the Markdown that produces it and its props.

To use them, follow [Set up components]($docs.set-up-components) first.

## Write a tag

A block component starts with two colons and its name and ends with two colons. The text between them is its content:

```md
::callout{title="Careful"}
This applies to new pages only.
::
```

A component that holds other components takes one colon more than the ones inside:

```md
:::tabs
::tab{title="Monthly"}
€12 a month.
::
::tab{title="Yearly"}
€120 a year.
::
:::
```

An inline component has one colon and stands in a sentence. Its text goes in square brackets:

```md
Press :kbd[Ctrl] + :kbd[S] to save. The feature is :badge[new]{color="success"}.
```

Some components have a named slot. It starts with `#` and its name on a line of its own, see [`quiz-question`]($docs.components-learning).

## Write props

Props go in curly braces after the name: `::card{title="Garden" iconColor="primary"}`.

- Write each name exactly as in the lists. A name with two words is camelCase (`iconColor`, `defaultValue`). `icon-color` is an unknown prop.
- A yes/no prop works on its own (`open`) or with `"true"` and `"false"`.
- A prop marked *required* must be there. `ginko check` names a missing one.

## Props many tags share

| Prop | Values | Meaning |
| --- | --- | --- |
| `icon` | An Iconify name such as `lucide:book-open`. A bare name means Lucide. | Shows an icon. It needs `@nuxt/icon` and the icon set, see [Add icons]($docs.set-up-components#add-icons). Notices also know six built-in names. |
| `appearance` | `quiet` or `tint` | A border or a filled area, see [Border or fill]($docs.theme-the-components#border-or-fill). |
| `title` | text | The heading of the component. |

The tags with `appearance` are `callout` and its short forms, `aside`, `excerpt`, `accordion`, `collapse`, `tabs`, `cards`, `card`, `read-more`, `inline-toc`, `steps`, `files`, `api` and `quiz`.

## Where a tag may stand

- A Markdown field takes components only with the profile `page`, see [Field types]($docs.field-types#text-fmarkdown).
- Some tags belong together: `tab` stands only in `tabs`, `column` only in `layout`, `timeline-item` only in `timeline`, `accordion-item` only in `accordion`, `quiz-question` only in `quiz`, `api-param` only in `api`.
- Ginko never renders the HTML elements `embed` or `iframe` from Markdown. `::embed` is always the component.

## Fixed texts

The components have fixed texts, for example the label of the copy button. They follow the language of the page. A site changes one in its own message file under `components`:

```json [i18n/en.json]
{ "components": { "code": { "copy": "Copy" } } }
```

| Key | English text |
| --- | --- |
| `code.copy`, `code.copied`, `code.copyFailed` | Copy code, Copied, Could not copy |
| `code.terminal`, `code.untitled` | Terminal, Code {number} |
| `media.zoom`, `media.close`, `media.play` | Enlarge image, Close, Play |
| `media.consent` | When you play, {provider} loads content and may set cookies. |
| `embed.load`, `embed.consent` | Load content; When you load this, {provider} loads content and may set cookies. |
| `quiz.progress`, `quiz.question` | Question {current} of {total}, Question {number} |
| `quiz.back`, `quiz.next`, `quiz.check`, `quiz.results`, `quiz.retry` | Back, Next, Check answer, See results, Try again |
| `quiz.correct`, `quiz.incorrect`, `quiz.multiple` | Correct, Not correct, (select all that apply) |
| `quiz.score`, `quiz.perfect`, `quiz.retryPrompt` | {correct} of {total} correct; Perfect score.; Keep learning and try again. |
| `api.defaultGroup`, `api.required`, `api.deprecated`, `api.since` | Parameters, required, deprecated, since {version} |
| `collapse.more`, `collapse.lines` | Show more, Show all {count} lines |
| `toc.title` | On this page |

`components` is a reserved name. Do not use it for your own messages.
