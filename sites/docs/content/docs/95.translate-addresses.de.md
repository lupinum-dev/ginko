---

Diese Anleitung gibt einer Seite in jeder Sprache einen eigenen Pfad: `/about` auf Englisch und `/de/ueber-uns` auf Deutsch. Am Ende zeigen beide Adressen dieselbe Seite, Links folgen der Sprache der Leser, und die Sitemap nennt beide.

Die Anleitung gilt für feste Seiten wie „Über uns“ oder „Kontakt“. Für die Seiten von Einträgen lies [Einträgen eigene Seiten geben]($docs.entry-pages).

## Bevor du beginnst

Die Seite hat zwei Sprachen. [Eine Sprache hinzufügen]($docs.add-a-language) zeigt, wie du eine ergänzt.

## Schritte

::steps
#### Die Seite mit dem Pfad der Hauptsprache anlegen

Der Dateiname ist der Pfad in der Hauptsprache:

```vue [app/pages/about.vue]
<script setup lang="ts">
definePageMeta({ i18n: { paths: { de: '/ueber-uns' } } })
</script>

<template>
  <main>
    <h1>About us</h1>
  </main>
</template>
```

`definePageMeta` nennt den Pfad in jeder weiteren Sprache, ohne das Sprachpräfix. Ginko ergänzt `/de` selbst. Ohne diese Zeile ist die deutsche Adresse `/de/about`.

#### Die Seite in der Konfiguration eintragen

Trag die Seite in `pages` in `ginko.config.ts` ein, mit dem Präfix:

```ts [ginko.config.ts]
pages: {
  home: { en: '/', de: '/de' },
  about: { en: '/about', de: '/de/ueber-uns' },
},
```

Ginko nutzt `pages` für die Sitemap, und der Schlüssel `about` gibt der Seite einen Namen für Links.

#### Die Seite verlinken

Schreib nie den Pfad einer Sprache in einen Link. Frag stattdessen nach dem Pfad:

```vue
<script setup lang="ts">
const path = useGinkoPath()
</script>

<template>
  <NuxtLink :to="path('about')">About us</NuxtLink>
</template>
```

`path('about')` liefert `/about` auf einer englischen Seite und `/de/ueber-uns` auf einer deutschen. `path('about', 'de')` liefert auf jeder Seite den deutschen Pfad.

#### Das Ergebnis prüfen

1. `/about` und `/de/ueber-uns` zeigen die Seite.
2. `/de/about` antwortet mit 404. Eine Seite hat genau eine Adresse pro Sprache.
3. `/sitemap.xml` nennt beide Adressen.
::

## Eine Seite, die nicht in der Konfiguration steht

`localePath` aus `useI18n` übersetzt einen Pfad der Hauptsprache ohne Schlüssel:

```ts
const { localePath } = useI18n()
localePath('/about')        // '/about', oder '/de/ueber-uns' auf einer deutschen Seite
localePath('/about', 'de')  // '/de/ueber-uns'
```

Nimm es nur für Seiten deiner eigenen Seite. Für einen Eintrag nimmst du `item.url`.
