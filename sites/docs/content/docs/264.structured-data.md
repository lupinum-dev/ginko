Search engines show richer results for pages that describe themselves as data: a business with its address, a question with its answer, an event with its date. The format is JSON-LD with the vocabulary of schema.org. This guide adds it to your pages.

## What the site writes by itself

The start page has a `WebSite` entry with the name, the address and the language of the site. With `seo.organization` in the config, it also has an `Organization` entry:

```ts [ginko.config.ts]
seo: {
  organization: {
    logo: '/logo.png',
    sameAs: ['https://www.instagram.com/linde'],
  },
},
```

`sameAs` lists the profiles of the business elsewhere.

## Steps

::steps
#### Use the helper of a ready-made brick

The bricks of `@lupinum/ginko/basics` have helpers that build the data from their entries. For questions and answers:

```vue [app/pages/questions.vue]
<script setup lang="ts">
import { faqJsonLd } from '@lupinum/ginko/basics'

const faq = useGinko('faq')
useGinkoSeo(() => ({
  title: 'Questions',
  jsonLd: [faqJsonLd(faq.value.items.map((item) => item.data))],
}))
</script>
```

| Brick | Helper | schema.org type |
| --- | --- | --- |
| `site()` | `siteJsonLd` | Organization, LocalBusiness or NGO |
| `people()` | `personJsonLd` | Person |
| `posts()` | `postJsonLd` | BlogPosting |
| `jobs()` | `jobJsonLd` | JobPosting |
| `faq()` | `faqJsonLd` | FAQPage |

#### Write your own

For anything else, pass an object to `jsonLd`:

```ts
useGinkoSeo(() => ({
  title: post.value.data.title,
  type: 'article',
  jsonLd: [{
    '@context': 'https://schema.org',
    '@type': 'NewsArticle',
    headline: post.value.data.title,
    datePublished: post.value.data.date,
  }],
}))
```

#### Check the result

Open the source of the page and search for `application/ld+json`. The block holds your object. Then paste the address of the live page into the Rich Results Test of Google. It shows which results the page can get.
::

## A breadcrumb trail

`breadcrumbJsonLd` builds the trail from the start page to the current page:

```ts
import { breadcrumbJsonLd } from '@lupinum/ginko'

const { url } = useGinkoSite()
const crumbs = useGinkoBreadcrumbs(['pages'])
useGinkoSeo(() => ({
  title: page.value.data.title,
  jsonLd: [breadcrumbJsonLd(crumbs.value, url)],
}))
```
