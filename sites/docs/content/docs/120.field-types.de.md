title: Feldtypen
slug: feldtypen
description: Jeder Feldtyp eines Bausteins. Die Einstellungen jedes Typs, ihre Standardwerte und Grenzen und der Wert, den die Seite liest.
---

Ein Feld ist ein Wert in einem Baustein. Du baust es mit `f.<typ>(label, einstellungen)` aus `@lupinum/ginko`:

```ts
import { f } from '@lupinum/ginko'

const fields = {
  name: f.text('Name', { max: 120 }),
  price: f.money('Preis', { optional: true }),
}
```

Das Label ist der Name des Feldes im Editor. Es ist ein Text oder ein Text pro Sprache: `{ de: 'Name', en: 'Name' }`. Ein Label pro Sprache muss die Hauptsprache oder Englisch enthalten.

Wie Felder in einen Baustein passen, steht unter [Bausteine]($docs.bricks).

## Alle Typen

| Funktion | Enthält | Wert, den die Seite liest | Übersetzbar |
| --- | --- | --- | --- |
| [`f.text`](#text-ftext) | einen kurzen Text | `string` | ja, mit `format` nein |
| [`f.longtext`](#text-flongtext) | einen Text aus mehreren Sätzen | `string` | ja |
| [`f.markdown`](#text-fmarkdown) | formatierten Text | Markdown-Baum | ja |
| [`f.slug`](#text-fslug) | die Adresse eines Eintrags | `string` | immer |
| [`f.number`](#zahlen-fnumber) | eine Zahl | `number` | nein |
| [`f.money`](#zahlen-fmoney) | einen Betrag | `{ amount, currency }` | nein |
| [`f.boolean`](#zahlen-fboolean) | ja oder nein | `boolean` | nein |
| [`f.date`](#datum-und-zeit-fdate) | einen Tag | `'2026-10-12'` | nein |
| [`f.time`](#datum-und-zeit-ftime) | eine Uhrzeit | `'18:30'` | nein |
| [`f.daterange`](#datum-und-zeit-fdaterange) | einen ersten und einen letzten Tag | `{ from, to }` | nein |
| [`f.choice`](#auswahl-fchoice) | eine von mehreren Optionen | der Wert der Option | nein |
| [`f.choices`](#auswahl-fchoices) | mehrere Optionen | Liste der Werte | nein |
| [`f.list`](#listen-flist) | Zeilen mit Spalten | Liste von Zeilen, jede mit `_id` | je Spalte |
| [`f.image`](#bilder-und-dateien-fimage) | ein Foto | `{ url, alt, width, height }` | nur `alt` |
| [`f.file`](#bilder-und-dateien-ffile) | ein PDF | `{ url, name, size }` | nein |
| [`f.ref`](#verweise-fref) | einen Eintrag einer Sammlung | die ID des Eintrags | nein |
| [`f.refs`](#verweise-frefs) | mehrere Einträge einer Sammlung | Liste von IDs | nein |

„Übersetzbar“ heißt: Das Feld hat einen Wert pro Sprache. Alle anderen Felder haben einen Wert für die ganze Seite.

## Einstellungen für jeden Typ

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `optional` | `true` | Pflicht | Das Feld darf leer bleiben. |
| `hint` | Text, oder ein Text pro Sprache | keiner | Ein Hilfetext unter dem Feld im Editor. |
| `default` | der Wert des Feldes | keiner | Der Wert, mit dem ein neuer Eintrag beginnt. `f.markdown`, `f.image` und `f.file` haben kein `default`. |
| `translate` | `false` oder `'manual'` | übersetzt | `false` gibt einem übersetzbaren Typ einen Wert für alle Sprachen. `'manual'` lässt das Feld übersetzt und schaltet die Übersetzungsvorschläge aus. |
| `showWhen` | `{ field, is }` oder `{ field, not }` | immer sichtbar | Der Editor zeigt das Feld nur, solange ein Feld daneben diesen Wert hat. Ein fehlender Wert zählt als „nicht“. Der gespeicherte Wert und die Prüfungen bleiben gleich. |
| `group` | Text, oder ein Text pro Sprache | keine | Der Editor zeigt das Feld unter dieser Überschrift. Nicht für die Spalten einer Liste. |

Ein Pflichtfeld mit `showWhen` ist nur Pflicht, solange der Editor es zeigt. Sein Typ in der Seite ist deshalb optional.

Schreib ein `default` so, wie die Seite den Wert liest. Zwei Typen weichen ab: Ein übersetzbarer Text nimmt einen Text (die Hauptsprache) oder einen Text pro Sprache, und `f.money` nimmt `{ amount: 1250 }` ohne die Währung.

Eine Einstellung, die ein Typ nicht hat, ist ein Typfehler in `ginko.config.ts`.

## Text

### `f.text`

Ein kurzer Text in einer Zeile.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `max` | Zahl | `200` | Höchste Zeichenzahl. Höchstens `500`, mit `format: 'url'` höchstens `2000`. |
| `format` | `'url'`, `'email'` oder `'tel'` | keines | Der Text muss eine Adresse dieser Art sein. Ein Text mit `format` ist nicht übersetzbar. |

```ts
phone: f.text('Telefon', { format: 'tel' }),
```

### `f.longtext`

Ein einfacher Text aus mehreren Sätzen, ohne Formatierung.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `max` | Zahl | `2000` | Höchste Zeichenzahl. Höchstens `5000`. |

### `f.markdown`

Formatierter Text. Die Seite liest einen Markdown-Baum und zeigt ihn mit `<GinkoMarkdown>`.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `profile` | `'inline'`, `'basic'`, `'rich'` oder `'page'` | `'rich'` | Was der Text enthalten darf, siehe die Tabelle unten. |
| `max` | Zahl | `50000` | Höchste Zeichenzahl. Höchstens `500000`. |

Jedes Profil erlaubt, was das Profil davor erlaubt, und mehr:

| Profil | Erlaubt |
| --- | --- |
| `inline` | Einen Absatz mit fett, kursiv, durchgestrichen, Code und Links. |
| `basic` | Dazu Überschriften h2 bis h4, Listen, Checklisten, Zitate, Trennlinien und Fußnoten. |
| `rich` | Dazu Tabellen, Bilder, Codeblöcke, Formeln und Mermaid-Diagramme. |
| `page` | Dazu h1, h5, h6 und Komponenten wie `::callout`. |

In einem Baustein mit `source: 'files'` ist das Markdown-Feld der Text der Datei unter dem Frontmatter. Ein solcher Baustein hat höchstens ein Markdown-Feld, und seine Listen haben keine Markdown-Spalte.

### `f.slug`

Die Adresse eines Eintrags, zum Beispiel `eroeffnung` in `/neuigkeiten/eroeffnung`. Ginko bildet sie einmal aus einem anderen Textfeld. Jede Sprache hat ihren eigenen Slug.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `from` | Name eines `text`- oder `longtext`-Feldes | Pflicht | Das Feld, aus dem der Slug entsteht. |

Ein Slug ist ein Feld des Bausteins selbst: Eine Liste hat keine Slug-Spalte. Eine Sammlung mit `route` braucht ein Slug-Feld mit dem Namen `slug`. Siehe [Routen und Slugs]($docs.bricks#routen-und-slugs).

## Zahlen

### `f.number`

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `min` | Zahl | Pflicht | Kleinster Wert. |
| `max` | Zahl | Pflicht | Größter Wert. |
| `step` | Zahl | Pflicht | Der Abstand zwischen zwei Werten, größer als `0`. Nimm `1` für ganze Zahlen. |
| `unit` | Text | keine | Eine Einheit neben dem Feld, zum Beispiel `kg`. |

```ts
seats: f.number('Plätze', { min: 1, max: 200, step: 1 }),
```

### `f.money`

Ein Betrag in der kleinsten Einheit seiner Währung. 12,50 € sind `{ amount: 1250, currency: 'EUR' }`. Eine Währung ohne Untereinheit wie JPY steht in ganzen Einheiten.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `min` | Zahl | `0` | Kleinster Betrag in der kleinsten Einheit. Nicht negativ. |
| `max` | Zahl | `100000000` | Größter Betrag in der kleinsten Einheit. Höchstens `100000000`. |
| `currency` | ISO-4217-Code | die `currency` der Seite | Die Währung dieses Feldes, zum Beispiel `'CHF'`. |

Zeig den Wert mit [`formatMoney`]($docs.reading-content#formatmoney).

### `f.boolean`

`true` oder `false`. Keine eigenen Einstellungen.

## Datum und Zeit

### `f.date`

Ein Tag als `YYYY-MM-DD`. Der Tag gilt in der Zeitzone der Seite (`timeZone` in `ginko.config.ts`). Keine eigenen Einstellungen.

### `f.time`

Eine Uhrzeit als `HH:MM`.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `after` | Name eines anderen `time`-Feldes des Bausteins | keines | Diese Zeit muss später sein als jenes Feld. Ginko prüft das, wenn beide einen Wert haben. |

```ts
from: f.time('Öffnet um'),
to: f.time('Schließt um', { after: 'from' }),
```

### `f.daterange`

Ein erster und ein letzter Tag: `{ from: '2026-10-12', to: '2026-10-14' }`. Keine eigenen Einstellungen.

## Auswahl

### `f.choice`

Eine von mehreren Optionen.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `options` | Liste der Optionen | Pflicht | 1 bis 50 Optionen. Jeder Wert kommt einmal vor. |

Eine Option ist ein Text, oder `{ value, label }`, wenn der Editor einen anderen Namen zeigt als den gespeicherten Wert. Die Seite liest nur den Wert. Zeig in der Seite deinen eigenen Text für jeden Wert.

```ts
day: f.choice('Tag', { options: [{ value: 'mo', label: 'Montag' }, { value: 'tu', label: 'Dienstag' }], default: 'mo' }),
```

In der Seite hat dieses Feld den Typ `'mo' | 'tu' | UnknownChoice`. `UnknownChoice` steht für eine Option, die ein späteres Release ergänzt. Gib ihr einen Ersatztext.

### `f.choices`

Mehrere der Optionen, als Liste von Werten.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `options` | Liste der Optionen | Pflicht | Wie bei `f.choice`. |
| `max` | Zahl | alle Optionen | So viele Optionen darf ein Eintrag höchstens wählen. |
| `askAgainWhen` | Name eines `text`- oder `longtext`-Feldes daneben | keines | Ändert sich dieser Text in der Hauptsprache und die Auswahl bleibt, fragt der Editor, ob die Auswahl noch stimmt. |

```ts
allergens: f.choices('Allergene', { options: ['gluten', 'milk', 'nuts'], askAgainWhen: 'dish' }),
```

## Listen

### `f.list`

Zeilen mit denselben Spalten, zum Beispiel die Tage eines Mittagsmenüs. Die Seite liest eine Liste von Zeilen. Jede Zeile hat ihre Spalten und eine `_id`, die gleich bleibt, wenn Zeilen ihren Platz wechseln.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `fields` | Felder | Pflicht | Die Spalten. Jede Spalte ist ein Feld beliebigen Typs außer `f.list` und `f.slug`. |
| `itemLabel` | Text, oder ein Text pro Sprache | Pflicht | Der Name einer Zeile im Editor, zum Beispiel „Tag“. |
| `max` | Zahl | Pflicht | Höchste Zeilenzahl, `1` bis `50`. |
| `min` | Zahl | `0` | Kleinste Zeilenzahl, `0` bis `max`. |
| `unique` | Name einer Spalte | keine | Der Wert dieser Spalte muss in jeder Zeile verschieden sein. Die Spalte ist Pflicht und hat den Typ `choice`, `date`, `time` oder `text` ohne Übersetzung. |

```ts
days: f.list('Tage', {
  itemLabel: 'Tag',
  fields: {
    day: f.choice('Tag', { options: ['mo', 'tu', 'we'] }),
    dish: f.text('Gericht', { max: 200 }),
    price: f.money('Preis', { optional: true }),
  },
  min: 3, max: 3, unique: 'day',
}),
```

Mit `min` gleich `max` und einer `unique`-Auswahlspalte kommt jede Option genau einmal vor.

Ein Spaltenname beginnt mit einem Kleinbuchstaben und hat nur Buchstaben und Ziffern. `_id` ist vergeben.

## Bilder und Dateien

### `f.image`

Ein Foto. Die Seite liest `{ url, alt, width, height }` und `focus: { x, y }`, wenn die Inhaberin einen Fokuspunkt gesetzt hat. Zeig es mit `<GinkoImage>`.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `aspect` | ein Seitenverhältnis wie `'3:2'`, oder benannte Seitenverhältnisse | keines | Die Form, in der die Seite das Foto zeigt. Der Editor zeigt das Foto in dieser Form. |

```ts
photo: f.image('Foto', { aspect: { card: '3:2', header: '21:9' } }),
```

Bei benannten Seitenverhältnissen wählt `<GinkoImage frame="card">` eines aus. `aspect` ändert keinen gespeicherten Wert.

Die Beschreibung `alt` ist in der Hauptsprache Pflicht und hat höchstens 300 Zeichen. Sie ist der einzige Teil eines Bildes, der übersetzbar ist.

### `f.file`

Eine Datei zum Herunterladen. Die Seite liest `{ url, name, size }`.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `accept` | `['pdf']` | Pflicht | Die Dateitypen, die das Feld annimmt. PDF ist der einzige. |
| `maxBytes` | Zahl | Pflicht | Größte Dateigröße in Bytes. Höchstens 10 MB. |

```ts
menu: f.file('Speisekarte als PDF', { accept: ['pdf'], maxBytes: 5 * 1024 * 1024 }),
```

## Verweise

### `f.ref`

Zeigt auf einen Eintrag einer Sammlung. Die Seite liest die ID dieses Eintrags.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `to` | Name eines Sammlungs-Bausteins | Pflicht | Die Sammlung, aus der der Eintrag kommt. |

### `f.refs`

Zeigt auf mehrere Einträge einer Sammlung. Die Seite liest eine Liste von IDs.

| Einstellung | Typ | Standard | Bedeutung |
| --- | --- | --- | --- |
| `to` | Name eines Sammlungs-Bausteins | Pflicht | Die Sammlung, aus der die Einträge kommen. |
| `max` | ganze Zahl über `0` | keine Grenze | Höchste Zahl der Einträge. |

```ts
authors: f.refs('Autoren', { to: 'authors', max: 3 }),
```
