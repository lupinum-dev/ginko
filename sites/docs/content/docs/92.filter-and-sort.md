This guide shows a part of a collection: only the entries that match, in the order you want. At the end, a page lists the vegan items that cost at most 4 euros, most expensive first.

## Before you start

A page lists a collection with `useGinko`. [Read content in a page]($docs.read-content-in-a-page) shows how. The examples use a collection `prices` with `title`, `price` (money) and `vegan` (yes/no).

## Steps

::steps
#### Replace useGinko with useGinkoQuery

`useGinkoQuery` takes the name of the brick and a query:

```vue
<script setup lang="ts">
const cheapVegan = useGinkoQuery('prices', {
  where: { vegan: true, price: { lte: { amount: 400 } } },
  order: 'price desc, title',
  limit: 10,
})
</script>

<template>
  <ul>
    <li v-for="item in cheapVegan.items" :key="item.id">{{ item.data.title }}</li>
  </ul>
  <p>{{ cheapVegan.total }} items</p>
</template>
```

- `where` names a value or a condition per field. Every field must match.
- `order` names the fields to sort by. `desc` sorts downward, and `asc` is the default.
- `limit` is the largest number of entries.

The result has `items` and `total`, the number of all matches.

#### Check the result

With the entries Coffee (3.50, vegan), Tea (2.80, vegan), Cake (4.20, not vegan) and Soup (6.50, vegan), the page shows "Coffee, Tea" and "2 items".
::

## Conditions

A field in `where` takes a value, which the field must equal, or one of these conditions:

| Condition | Matches when the field |
| --- | --- |
| `eq`, `ne` | is equal, or is not equal. For a list value, one element counts. |
| `gt`, `gte`, `lt`, `lte` | is greater or smaller. Money compares by `amount`, a date range by its first day. |
| `in` | is equal to one of the values in a list |
| `contains` | is a text that contains the text, or a list that contains the value. Upper and lower case count the same. |

An amount is in minor units: `{ lte: { amount: 400 } }` means at most 4.00.

## Show a page at a time

`limit` with `page` returns one page of the matches. `page` starts at 1:

```ts
const paged = useGinkoQuery('prices', { limit: 2, page: 2 })
```

The result also has `page` and `pages`. With four entries, `paged.items` holds entries 3 and 4, and `paged.pages` is 2.

## Count the values of a field

`facets` counts the values of fields over all matches, for example for filter buttons with a number:

```ts
const counted = useGinkoQuery('prices', { facets: ['vegan'] })
// counted.value.facets is { vegan: { true: 3, false: 1 } }
```

## Link to the previous and next entry

`useGinkoNeighbors` returns the entries before and after one entry, for example below an article:

```ts
const neighbors = useGinkoNeighbors('prices', () => item.id)
// neighbors.value.prev and neighbors.value.next are entries or undefined
```

It uses the order of the brick. Pass `{ order: 'date desc' }` as the third argument for another order.

## What the query reads

`useGinkoQuery` works on the content that the page already has. It asks no database and no server. A field that the brick does not have is an error in your editor.
