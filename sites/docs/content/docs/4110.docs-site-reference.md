This page lists what the docs kit `@lupinum/ginko-docs` offers. The guides start at [Start a docs site]($docs.start-a-docs-site).

## Entry points

Import only these paths. Every other file in the package is internal and can change in any release.

| Entry point | What it is |
| --- | --- |
| `@lupinum/ginko-docs` | The Nuxt layer for `extends` in `nuxt.config.ts`. It adds the pages, the layout, the components, the CSS and `@lupinum/ginko-components`. |
| `@lupinum/ginko-docs/config` | The bricks and page addresses for `ginko.config.ts`. |
| `@lupinum/ginko-docs/pages` | A Nuxt module that registers the pages of the kit. The layer loads it itself. |
| `@lupinum/ginko-docs/icons` | A Nuxt module that bundles the icons at build time. The layer loads it itself. |

Do not add the two modules to `modules`. `extends: ['@lupinum/ginko-docs']` brings them along.

The only option in `nuxt.config.ts` is `ginkoDocs.brick`: the key of the docs brick when it is not `docs`.

## Config functions

```ts
import { blogCollections, blogPages, changelogCollection, changelogPages, components, docsCollection, docsHome, homePages } from '@lupinum/ginko-docs/config'
```

| Export | Returns |
| --- | --- |
| `docsCollection({ locales, base?, source?, brick?, navExtras?, label?, max? })` | The docs brick. |
| `docsHome({ source? })` | The start page brick: `content/home.md`. |
| `blogCollections({ locales, source?, max? })` | The blog: `{ posts, authors }`. Spread it into `bricks`. |
| `changelogCollection({ source?, max? })` | The changelog brick. |
| `homePages({ locales })` | The addresses of the start page by language, for `pages.home`. |
| `blogPages({ locales })` | The addresses of the blog list, for `pages.blog`. |
| `changelogPages({ locales })` | The addresses of the changelog, for `pages.changelog`. |
| `components` | The registry of the Markdown components, for `components` in `defineSite`. |

Options of `docsCollection`:

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `locales` | list of language codes | required | The languages of the site, the main one first. |
| `base` | path | `'/docs'` | The address of the docs. Other languages get their prefix: `/de/docs`. |
| `source` | `'files'` or `'platform'` | `'files'` | Where the pages live. With `'platform'`, editors change them in the Studio. |
| `brick` | text | `'docs'` | The key of the brick, when it is not `docs`. Set `ginkoDocs.brick` to the same key. |
| `navExtras` | boolean | `true` | `false` leaves out the fields `tab`, `badge` and `icon`. |
| `label` | text | `'Docs'` | The name of the brick in the Studio. |
| `max` | number | `500` | Most pages. |

Set `navExtras` when the site starts. On a site with released pages it removes fields, which the platform refuses; retire the three fields there, see [Release a schema change]($docs.release-a-schema-change).

The kit finds its content by brick key. Keep these names: `docs`, `home`, `posts`, `authors` and `changelog`. Only `docs` is required, and only `docs` can have another key.

## Addresses

| Address | Page | Exists when |
| --- | --- | --- |
| `<base>` | Leads to the first docs page | always |
| `<base>/<name>` | One docs page | always |
| `/` | The start page, or the first docs page | the site has no page of its own there |
| `/blog`, `/blog/<name>`, `/blog/rss.xml` | The blog, a post, the feed | the bricks `posts` and `authors` exist |
| `/changelog` | All releases | the brick `changelog` exists |

Other languages have their prefix: `/de/blog`. A page of the site at the same address wins.

## Fields of a docs page

The frontmatter of a file in `content/docs/`:

| Field | Required | Meaning |
| --- | --- | --- |
| `title` | yes | The title of the page. |
| `description` | yes | One or two sentences, for search results and link previews. |
| `navTitle` | no | A short title for the navigation, the breadcrumbs and the links to the page before and after. |
| `section` | no | Starts a group in the navigation with this heading. |
| `parent` | no | Nests the page under another one: `parent: docs/<name>`. |
| `tab` | no | Starts a tab above the navigation. |
| `badge` | no | A short label after the title, at most 20 characters. |
| `icon` | no | An Iconify name. Set it in the main language only. |
| `slug` | no | The address of the page in this language. Without it, the file name. |

## Options

The options go under `docs` in `app/app.config.ts`. All are optional. TypeScript checks them without an import.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `title` | text | `name` of the site | The name in the header. |
| `logo` | `{ light, dark?, wordmark? }` | none | A logo before the title. `dark` shows in dark mode. `wordmark: true` shows the logo without the title. |
| `theme` | `'default'` or `'green'` | `'default'` | The colour preset. |
| `nav` | list of `{ id, href }` | none | Header links after Docs, Blog and Changelog. Text: message `docs.nav.<id>`. |
| `social` | list of `{ icon, href, label }` | none | Icon links at the end of the header. |
| `banner` | `{ id, href? }` | none | A notice above the header that readers can close. Text: message `docs.banner.<id>`. |
| `repository` | `{ url, branch?, editUrl?, issueUrl? }` | none | Adds "Edit this page" to pages from files, and "Report an issue" for GitHub. |
| `studioEditLink` | boolean | `false` | Adds "Edit this page" to pages stored on the platform, with a link to the Studio. |
| `markdownActions` | `{ copy?, openIn? }` | copy on, both chats | "Copy page" and the chats its menu opens the page in: `'chatgpt'`, `'claude'`. `[]` for none. |
| `search` | boolean | `true` | `false` leaves out the search of the kit. |
| `footer` | `{ links?, attribution? }` | attribution on | Footer links `{ id, href }` with the text from `docs.footer.<id>`. `attribution: false` removes "Built with Ginko". |

Details:

- An internal path in `nav`, `footer.links` and `banner.href` follows the language of the reader: `/guide` becomes `/de/guide`. A full URL stays as written.
- A reader who closes the banner does not see it again. A new `id` shows it to everyone.
- Built-in `social` icons: `docs:github`, `docs:discord`, `docs:x`, `docs:bluesky`, `docs:mastodon`, `docs:linkedin`, `docs:youtube`. Any other Iconify name works too.
- `repository.branch` is `main` by default. `editUrl` is a template with `{url}`, `{branch}` and `{source}`; the default is `{url}/edit/{branch}/{source}`. `issueUrl` is a template with `{url}`, `{title}` and `{page}`.

## Components

These components are public and stay stable between releases:

| Component | Props and slots | Purpose |
| --- | --- | --- |
| `<DocsSearch />` | `shortcut` (default `true`): `/` and Ctrl or ⌘ K open the search | The search, for example in the header of the site |
| `<DocsLanguage />` | `list`: a row of links, not a menu | The languages of the current page |
| `<DocsThemeToggle />` | `segmented`: the switch with Auto, Light and Dark | The light/dark switch |
| `<DocsShell>` | slot `default` for the page, slot `bar` for controls in the phone bar | Navigation and search around a page of your own |
| `<Icon name="lucide:…" />` | `name` | An icon from the bundle of the kit. If the site installs `@nuxt/icon`, its `Icon` wins. |

Two empty components are places for your own parts, see [Theme a docs site]($docs.docs-theming#steps): `DocsPageEnd` and `DocsSidebarEnd`.

## Tokens

The colour tokens and the sizes (`--docs-max`, `--docs-top` and more) are on [Theme a docs site]($docs.docs-theming#sizes).

## Internal

Everything else can change in any release: the other `Docs*` components, the `useDocs*` composables, the files under `app/` and the CSS classes. For the look, the tokens are the public interface, not the classes.
