This guide gives each page the texts and the image that a search result or a link preview shows. At the end, every page has its own title and description, and a link to it in a chat shows a card.

## Steps

::steps
#### Set the defaults of the site

```ts [ginko.config.ts]
export default defineSite({
  site: 'linde',
  name: 'Linden Inn',
  // …
  seo: {
    titleTemplate: '%s · Linden Inn',
    description: 'Country inn with a garden.',
  },
})
```

`titleTemplate` wraps the title of each page. `%s` stands for that title. `description` is the description of every page that sets none.

#### Call useGinkoSeo on every page

```vue [app/pages/news/[slug].vue]
<script setup lang="ts">
const route = useRoute()
const post = useGinkoEntry('news', () => route.params.slug)

useGinkoSeo(() => ({
  title: post.value.data.title,
  description: 'News from the Linden Inn.',
  image: post.value.data.photo?.url,
  type: 'article',
}))
</script>
```

Pass a function, so the values follow the content. On a page with nothing of its own, call `useGinkoSeo({})`: the page then has the name of the site as its title and the description of the site.

A page that does not call `useGinkoSeo` has no title.

#### Check the result

Open the page and look at its source. For the entry "We are open":

```html
<title>We are open · Linden Inn</title>
<meta name="description" content="News from the Linden Inn.">
<meta property="og:title" content="We are open">
<meta property="og:type" content="article">
<meta property="og:image" content="https://linde.example/img/kitchen.jpg">
<meta name="twitter:card" content="summary_large_image">
<link rel="canonical" href="https://linde.example/news/opening">
```

The canonical link and the `hreflang` links come by themselves, from `url` and the languages of the site.
::

## A title without the template

The start page often has a full title of its own. Turn the template off for it:

```ts
useGinkoSeo({ title: 'Linden Inn in Hallstatt', titleTemplate: false })
```

The title is then exactly "Linden Inn in Hallstatt".

## The options

| Option | Meaning | Default |
| --- | --- | --- |
| `title` | The title of the page. | the name of the site |
| `description` | The text under the title in a search result. | `seo.description` |
| `image` | The image of a link preview: a path under `public/`, a full address, or `{ url, width, height, alt }`. | `seo.image` |
| `type` | `'website'` or `'article'`. | `'website'` |
| `noindex` | `true` keeps the page out of search engines. | indexed |
| `jsonLd` | Structured data, see [Add structured data]($docs.structured-data). | none |

## Generated share cards

Every template comes with `nuxt-og-image`. Each page then gets a generated card of 1200 by 600 pixels: the name of the site, the title and the description of the page, on the brand colour `seo.color`. The image of the page, if it has one, goes into the card.

```ts [ginko.config.ts]
seo: {
  color: '#1e4032',
  organization: { logo: '/logo.png' },
},
```

The card needs nothing on the page: `useGinkoSeo` hands it the title and the description. On a server, the site needs the variable `NUXT_APP_SECRET`, see [Deploy to Vercel]($docs.deploy-to-vercel).

A site without `nuxt-og-image` shows the image you pass, or `seo.image`.

## Keep a page out of search engines

For a page from `pages`, such as a thank-you page after a form, name its key in the config:

```ts [ginko.config.ts]
pages: { thanks: { en: '/thanks', de: '/de/danke' } },
seo: { noindex: ['thanks'] },
```

The page leaves the sitemap and answers with `x-robots-tag: noindex` in every language.
