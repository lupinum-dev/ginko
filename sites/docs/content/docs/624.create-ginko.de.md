`create-ginko` legt eine neue Nuxt-Seite mit Ginko in einem neuen Ordner an. Der [Schnellstart]($docs.getting-started) verwendet ihn.

::code-group
```bash [npm]
npm create ginko@latest my-site
```
```bash [pnpm]
pnpm create ginko my-site
```
```bash [yarn]
yarn create ginko my-site
```
```bash [bun]
bun create ginko my-site
```
::

Ohne Optionen legt der Befehl den einfachen Starter auf Englisch an: eine Seite, die ihren Text aus `content/start.md` liest.

## Optionen

Mit npm schreibst du `--` vor die Optionen. Ohne `--` behält npm die Optionen für sich.

```bash
npm create ginko@latest my-site -- --template restaurant --locales de,en
```

| Option | Werte | Standard |
| --- | --- | --- |
| `--template <name>` | `starter`, `restaurant`, `local-business`, `company`, `saas`, `nonprofit`, `events`, `portfolio`, `blog` oder `docs` | der einfache Starter |
| `--locales <codes>` | Die Sprachen, die bleiben, mit Kommas dazwischen. Die erste ist die Hauptsprache. | alle Sprachen des Templates; `en` beim einfachen Starter |
| `-h`, `--help` | Zeigt die Optionen und die Templates. | |

`--template=<name>` und `--locales=<codes>` gehen auch. [Templates]($docs.templates) zeigt jedes Template mit einer Live-Demo.

### Sprachen der Templates

| Template | Sprachen |
| --- | --- |
| einfacher Starter | `en` oder `de`, eine davon |
| `starter`, `blog`, `company`, `docs`, `events`, `local-business`, `portfolio` | `en`, `de` |
| `restaurant` | `en`, `de`, `it` |
| `saas` | `en`, `de`, `fr` |
| `nonprofit` | `en`, `de`, `fr`, `ar` |

### Veraltete Optionen

| Option | Nimm stattdessen |
| --- | --- |
| `--preset gastro` | `--template restaurant` |
| `--preset docs` | `--template docs` |
| `--locale <code>` | `--locales <code>` |

Sie gehen noch und geben einen Hinweis aus. Ein späteres Release entfernt sie.

## Was der Befehl tut

Mit einem Template:

- kopiert der Befehl das Template in den Ordner
- behält er nur die Sprachen aus `--locales`: ihre Inhaltsdateien, ihre `i18n/<code>.json` und ihre Adressen
- verschiebt er die Daten von Beispieleinträgen, etwa Veranstaltungen, um ganze Wochen in diese Woche
- setzt er `site` in `ginko.config.ts`
- schreibt er eine `.env` mit `NUXT_APP_SECRET`, das die Teilen-Karten auf einem Server brauchen (siehe [Umgebungsvariablen]($docs.environment-variables))

Er installiert die Pakete nicht und startet kein git. Die letzten Zeilen der Ausgabe nennen die nächsten Befehle:

```text
Created my-site from the blog template in German.
The sample dates in 1 content file moved to this week.

Next:

  cd my-site
  npm install
  npm run dev
```

## Die Id der Seite

`site` in `ginko.config.ts` kommt aus dem Ordnernamen: in Kleinbuchstaben, jede Folge anderer Zeichen wird zu `-`, höchstens 40 Zeichen. Weicht die Id vom Ordnernamen ab, sagt der Befehl das:

```text
The site id is "my-caf-site": the folder name in lower case, with other characters replaced by "-", at most 40 characters. Change `site` in ginko.config.ts to use another one.
```

Wähle die Id vor dem ersten Release: Die Plattform kennt die Seite unter dieser Id.

## Fehler

Ein falscher Aufruf legt nichts an. Der Befehl gibt die Ursache und die Verwendung aus.

| Meldung | Exit-Code | Lösung |
| --- | --- | --- |
| `Give the name of the folder to create.` | 2 | Gib den Ordnernamen an. |
| `Unknown option "--colour".` | 2 | Nimm eine der Optionen oben. Prüfe bei npm, dass `--` vor den Optionen steht. |
| `Unknown template "nope". Choose one of: …` | 2 | Nimm einen Namen aus der Liste in der Meldung. |
| `Unknown locale "xx". The blog template has: en, de.` | 2 | Nimm die Sprachen, die das Template hat. |
| `The plain starter has one language. Choose one of: en, de, or use a --template.` | 2 | Gib eine Sprache an, oder wähle ein Template. |
| `The folder y exists and is not empty. Choose another name.` | 1 | Nimm einen neuen Ordnernamen, oder leere den Ordner. |
