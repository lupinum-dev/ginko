## What a preset is

A preset is a package of ready-made bricks. Each factory (`hours()`, `menu()` and so on) returns a brick that you add to `bricks`. Fields, labels, tasks and routes are already there. The components stay in your site, because their look belongs to your site.

## Restaurant: `@lupinum/ginko-preset-gastro`

For restaurants: `hours()`, `hourPlans()`, `notices()`, `lunch()`, `menu()`, `events()` and `gallery()` with the owner's tasks ("Closed today", "Fully booked today", change a price). It also has the 14 allergens for Austria and the functions `todayState` and `hoursOn` for opening hours. [`sites/restaurant`](https://github.com/lupinum-dev/ginko/tree/main/sites/restaurant) in the Ginko repository is a complete example. `npm create ginko my-site -- --preset gastro` starts a site with this preset.
