Diese Anleitung lässt Einträge nach einem Datum von selbst von der Seite verschwinden, zum Beispiel einen Hinweis, der am 15. August endet, oder eine Veranstaltung, die vorbei ist. Niemand muss daran denken, sie zu entfernen.

## Bevor du beginnst

Du hast eine Sammlung. [Inhalte modellieren]($docs.model-your-content) zeigt, wie du eine anlegst.

## Schritte

::steps
#### Ein Datumsfeld für den letzten Tag ergänzen

```ts [ginko.config.ts]
news: collection({
  label: 'Neuigkeiten',
  source: 'files',
  max: 100,
  order: { field: 'date', dir: 'desc' },
  visible: { mode: 'until', field: 'until' },
  fields: {
    title: f.text('Titel'),
    date: f.date('Datum'),
    until: f.date('Zeigen bis', { optional: true }),
    body: f.markdown('Text'),
  },
}),
```

`visible` nennt das Feld mit dem letzten Tag. Das Feld ist ein `date` oder ein `daterange`. Bei einem `daterange` zählt das Enddatum.

#### Das Datum an einem Eintrag setzen

```markdown [content/news/2.summer-break.md]
---
title: Summer break
date: 2026-07-01
until: 2026-08-15
---

Closed in August.
```

Der Eintrag ist bis einschließlich 15. August zu sehen. Ein Eintrag ohne Wert in `until` ist immer zu sehen.

#### Das Ergebnis prüfen

Setz `until` auf gestern. Dann gilt:

1. Die Liste enthält den Eintrag nicht.
2. Hat die Sammlung eine Route, antwortet die Seite des Eintrags mit 404.
3. `/sitemap.xml` nennt den Eintrag nicht.
::

## Links auf einen Eintrag, der endet

Ein verborgener Eintrag existiert für den Rest der Seite nicht. Ein Link aus einem Text auf ihn ist dann ein kaputter Link, und `ginko check` und der Build brechen ab:

```text
content/news/opening: Link $news.summer-break leads to no entry and no page.
```

Entferne so einen Link, wenn der Eintrag endet, oder verlinke eine Seite, die bleibt.

## Wie das Datum zählt

- Ein Datum gilt für den ganzen Tag, in der Zeitzone der Seite (`timeZone` in `ginko.config.ts`).
- `days` hält einen Eintrag länger. Mit `visible: { mode: 'until', field: 'when', days: 6 }` bleibt eine Veranstaltung sechs Tage nach ihrem Datum.
- Der Standard ist `{ mode: 'always' }`: Jeder Eintrag ist zu sehen.

Die Seiten brauchen dafür keinen Code. `useGinko` liefert nur die sichtbaren Einträge.

## Alte Einträge auf der Plattform aufräumen

Mit `deleteExpired: true` in `visible` löscht die Plattform verborgene Einträge, wenn ein neuer Eintrag Platz braucht. Ein täglicher Job löscht außerdem Einträge, die seit 30 Tagen verborgen sind. Ein gelöschter Eintrag lässt sich 30 Tage lang wiederherstellen.

Dateien werden nicht gelöscht. Ein Eintrag in einer Datei bleibt verborgen, bis du die Datei entfernst oder ihr Datum änderst.
