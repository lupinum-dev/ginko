## Was ein Preset ist

Ein Preset ist ein Paket mit fertigen Bausteinen. Jede Fabrik (`hours()`, `menu()` und so weiter) gibt einen Baustein zurück, den du in `bricks` einträgst. Felder, Beschriftungen, Aufgaben und Routen sind schon da. Die Komponenten bleiben in deiner Seite, weil das Aussehen zu deiner Seite gehört.

## Restaurant: `@lupinum/ginko-preset-gastro`

Für Gasthäuser: `hours()`, `hourPlans()`, `notices()`, `lunch()`, `lunchPlans()`, `menu()`, `events()` und `gallery()`, mit den Aufgaben der Wirtin („Heute geschlossen“, „Heute ausgebucht“, Preis ändern). Dazu die 14 EU-Allergene (`allergensEU`) und die Öffnungszeiten-Regeln `hoursOn` und `todayState`.

Eine neue Seite mit diesem Preset startest du so:

```bash
npm create ginko@latest mein-gasthaus -- --preset gastro --lang de
```

Der Starter zeigt Öffnungszeiten und eine Speisekarte, beide aus Dateien. Ohne `--lang de` ist der Starter englisch.

### Bausteine eintragen

```ts
// ginko.config.ts
import { defineSite } from '@lupinum/ginko'
import { hours, menu, notices } from '@lupinum/ginko-preset-gastro'

export default defineSite({
  site: 'mein-gasthaus',
  name: 'Mein Gasthaus',
  url: 'https://example.com',
  timezone: 'Europe/Vienna',
  locales: ['de'],
  currency: 'EUR',
  pages: { home: '/' },
  bricks: {
    hours: hours({ source: 'files' }),
    menu: menu({ allergens: 'none', source: 'files' }),
    notices: notices(),
  },
})
```

### Optionen

Jede Fabrik nimmt dieselben zwei Optionen:

- `lang`: die Hauptsprache der Seite, sonst `'de'`. Sie wählt nur Standard-Inhalte, etwa den Platzhalter im Mittagsmenü oder den Text „Heute sind wir ausgebucht.“, für `de` oder `en`. Die Beschriftungen im Studio sind immer Deutsch und Englisch.
- `source`: Ohne sie bearbeitet die Wirtin den Baustein auf der Ginko-Plattform. `'files'` liest ihn aus Markdown in `content/`, dann läuft die Seite ohne Plattform.

Manche Fabriken haben mehr Optionen: `calendar` bei `hours()`, `allergens` bei `menu()`, `lunch()` und `lunchPlans()` (`'EU'`, `'none'` oder eine eigene Liste), `weekOf` bei `lunch()`, `lunchBrick` bei `lunchPlans()` und `route` bei `events()` (Pflicht).

Die Öffnungszeiten-Regeln zählen österreichische Feiertage. Für ein anderes Land gib `hours({ calendar: 'DE' })` an (oder `'SG'`, oder eine eigene Funktion); `'none'` schaltet Feiertage ab.

### Öffnungszeiten anzeigen

```ts
import { todayState } from '@lupinum/ginko-preset-gastro'

const state = todayState('2026-10-26', { hours: { week: [], exceptions: [], holidays: 'closed' } })
// { kind: 'holiday', holiday: { de: 'Nationalfeiertag', en: 'Austrian National Day' } }
```

`todayState` gibt `open` (mit den Zeiten), `closed` (mit dem Grund der Wirtin), `holiday` oder `restDay` zurück. Die Zeiten verbindest du in deiner Sprache mit `spansText(state.times, 'und')`. Gib denselben `holidays`-Wert als `calendar` mit: `todayState(today, { hours, calendar: 'DE' })`.

Ein vollständiges Beispiel ist [`sites/restaurant`](https://github.com/lupinum-dev/ginko/tree/main/sites/restaurant) im Ginko-Repository. Es läuft im Repository gegen eine nachgebaute Plattform.
