This guide makes entries leave the site by themselves after a date, for example a notice that ends on 15 August or an event that is over. Nobody has to remember to remove them.

## Before you start

You have a collection. [Model your content]($docs.model-your-content) shows how to add one.

## Steps

::steps
#### Add a date field for the last day

```ts [ginko.config.ts]
news: collection({
  label: 'News',
  source: 'files',
  max: 100,
  order: { field: 'date', dir: 'desc' },
  visible: { mode: 'until', field: 'until' },
  fields: {
    title: f.text('Title'),
    date: f.date('Date'),
    until: f.date('Show until', { optional: true }),
    body: f.markdown('Text'),
  },
}),
```

`visible` names the field that holds the last day. The field is a `date` or a `daterange`. For a `daterange`, the end date counts.

#### Set the date on an entry

```markdown [content/news/2.summer-break.md]
---
title: Summer break
date: 2026-07-01
until: 2026-08-15
---

Closed in August.
```

The entry shows up to and including 15 August. An entry without a value in `until` always shows.

#### Check the result

Set `until` to yesterday. Then:

1. The list does not contain the entry.
2. If the collection has a route, the page of the entry answers 404.
3. `/sitemap.xml` does not name the entry.
::

## Links to an entry that ends

A hidden entry does not exist for the rest of the site. A link to it from a text is then a broken link, and `ginko check` and the build stop:

```text
content/news/opening: Link $news.summer-break leads to no entry and no page.
```

Remove such a link when the entry ends, or link to a page that stays.

## How the date counts

- A date counts for the whole day, in the time zone of the site (`timeZone` in `ginko.config.ts`).
- `days` keeps an entry longer. With `visible: { mode: 'until', field: 'when', days: 6 }`, an event stays six days after its date.
- The default is `{ mode: 'always' }`: every entry shows.

The pages need no code for this. `useGinko` returns only the visible entries.

## Clear out old entries on the platform

With `deleteExpired: true` in `visible`, the platform deletes hidden entries when a new entry needs room. A daily job also deletes entries that have been hidden for 30 days. A deleted entry can be restored for 30 days.

Files are not deleted. An entry in a file stays hidden until you remove the file or change its date.
