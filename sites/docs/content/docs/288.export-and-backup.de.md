Die Inhalte auf der Plattform gehören der Inhaberin der Seite. Diese Anleitung holt eine vollständige Kopie davon: einmal von Hand und jede Woche von selbst.

## Eine Sicherung im Studio herunterladen

Eine Inhaberin öffnet „Team“, dann „Backup“, und wählt „Download backup“. Der Download ist eine ZIP-Datei mit allen Inhalten, Entwürfe und entfernte Einträge eingeschlossen, und allen Bildern und PDFs. Team, Verlauf und Schlüssel sind nicht dabei.

## Von der Kommandozeile sichern

::steps
#### Einen Schlüssel für Sicherungen anlegen

Öffne im Studio „Team“, dann „Publishing keys“, dann „New key“. Wähle „Back up only“. So ein Schlüssel kann die Inhalte lesen und nichts veröffentlichen.

#### Den Export laufen lassen

```bash
export GINKO_PLATFORM=https://platform.example.com
export GINKO_KEY=ginko_linde_…
npx ginko export ginko-export-linde
```

Der Ordner muss neu oder leer sein. Ohne Ordnernamen nimmt der Befehl `ginko-export-<site>-<datum>`. Er gibt eine Zeile aus:

```json
{"ok":true,"dir":"ginko-export-linde","entries":7,"files":0}
```

#### Das Ergebnis prüfen

Der Ordner enthält `export.json` und einen Ordner `files/`:

- `export.json` hat das Schema und jeden Eintrag, auch die entfernten.
- `files/` hat jedes Bild und jedes PDF.

`export.json` wird zuletzt geschrieben. Ein Ordner mit dieser Datei ist vollständig.
::

## Jede Woche sichern

Lass den Export in CI nach Zeitplan laufen und bewahre den Ordner als Artefakt auf:

```yaml [.github/workflows/backup.yml]
on:
  schedule:
    - cron: '0 3 * * 1'
jobs:
  backup:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
      - uses: actions/setup-node@v6
        with: { node-version: 24 }
      - run: npm ci
      - run: npx ginko export backup
        env:
          GINKO_PLATFORM: ${{ secrets.GINKO_PLATFORM }}
          GINKO_KEY: ${{ secrets.GINKO_BACKUP_KEY }}
      - uses: actions/upload-artifact@v6
        with: { name: ginko-backup, path: backup }
```

## Wiederherstellen

Lupinum lädt einen Export-Ordner zurück in eine Seite. Schick den Ordner und sag, für welche Seite er ist.

## Die Plattform verlassen

Ein Export ist auch der Weg hinaus. `export.json` enthält jeden Text in jeder Sprache in einer dokumentierten Form. Ein Skript kann daraus Dateien für ein anderes System machen. [Vergleich und Umstieg]($docs.switching#die-plattform-verlassen) sagt, was du mitnimmst.
