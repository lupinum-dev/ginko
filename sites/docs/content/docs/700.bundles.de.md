Ein Bundle ist alles, was eine Seite liest: jeder Baustein mit seinen Werten in einer Sprache, als eine JSON-Antwort. `useGinko`, `useGinkoEntry` und `useGinkoQuery` lesen alle aus dem Bundle der aktuellen Anfrage.

Du lädst ein Bundle nie selbst. Diese Seite erklärt, was darin steht, damit du verstehst, warum sich eine Seite so verhält.

## Was in einem Bundle steht

- **Jeder Baustein der Seite.** Ein Einzelstück hat seine Werte. Eine Sammlung hat ihre Einträge, in der Reihenfolge, die der Baustein festlegt, jeden mit einer Id, seinen Werten und, mit einer `route`, seiner Adresse.
- **Eine Sprache.** Eine Seite mit drei Sprachen hat drei Bundles. Eine deutsche Seite liest das deutsche Bundle.
- **Werte, die fertig zum Anzeigen sind.** Die Arbeit unten ist erledigt, bevor die Seite das Bundle bekommt.

## Was erledigt ist, bevor die Seite liest

| Schritt | Ergebnis im Bundle |
| --- | --- |
| Prüfungen | Jeder Wert passt zu seinem Feld. Ein Wert, den die Regeln des Feldes ablehnen, kommt nie hinein. |
| Standardwerte | Ein Feld ohne Wert hat sein `default`, wenn das Feld eines setzt. |
| Übersetzung | Ein Text ohne Übersetzung enthält den Text der Hauptsprache, und der Eintrag listet das Feld in `fallback`. Siehe [Fehlende Übersetzungen]($docs.missing-translations). |
| Daten | Ein Eintrag außerhalb seiner Daten ist nicht im Bundle. Eine geplante Änderung, die fällig ist, gilt. |
| Entwürfe | Ein Entwurf ist nicht im Bundle der Live-Seite. |
| Markdown | Ein Markdown-Text ist ein Baum, kein String. Im Browser läuft kein Parser. |
| Links | Ein Link, geschrieben als `$news.opening`, ist die Adresse dieses Eintrags in dieser Sprache. |
| Bilder | Ein Bild hat seine Adresse, seine Größe und seine Beschreibung. |

Eine Seite zeigt also, was sie liest. Sie prüft keine Daten, wählt keine Sprache und parst kein Markdown.

## Warum eine Antwort pro Sprache

- **Eine Anfrage pro Seite.** Eine Seite mit Öffnungszeiten, einer Speisekarte und drei Hinweisen braucht ein Bundle, nicht fünf Abfragen. Die Seite lädt das Bundle einmal pro Anfrage, und jedes Composable liest daraus.
- **Keine halben Seiten.** Alle Bausteine stammen aus demselben Moment. Eine Seite zeigt nie neue Öffnungszeiten neben einem alten Hinweis.
- **Ein Fehlerfall.** Entweder ist das Bundle da, oder die Seite antwortet mit 503. Kein Teil einer Seite fehlt ohne Zeichen.
- **Typisiert.** Das Bundle folgt `ginko.config.ts`, also hat `menu.items[0].data.price` in deinem Editor einen Typ.

Der Preis ist die Größe: Ein Bundle enthält die ganze Seite, auch die Bausteine, die eine Seite nicht nutzt. Die [Grenzen]($docs.limits) einer Seite halten ein Bundle klein genug dafür.

## Woher ein Bundle kommt

| Quelle der Bausteine | Wer das Bundle baut | Wann |
| --- | --- | --- |
| Nur Dateien | Der Build | Beim Build. Der Dev-Server baut es neu, wenn sich eine Datei ändert. |
| Plattform | Die Plattform | Die Seite holt es, wenn sie eine Seite rendert. |
| Beides | Beide | Die Seite fügt die zwei Teile zusammen. Eine Seite merkt keinen Unterschied. |

Eine Seite, deren Bausteine alle aus Dateien kommen, fragt die Plattform nie. Ihre Inhalte ändern sich mit einem Deploy.

## Wie frisch ein Bundle ist

Auf einer Plattform-Seite hält ein Host wie Vercel jede gerenderte Seite höchstens 60 Sekunden. Eine veröffentlichte Änderung ist also innerhalb von 60 Sekunden auf der Seite. Mit einem Site-Token lässt die Plattform die geänderten Seiten sofort neu rendern, siehe [Umgebungsvariablen]($docs.environment-variables).

Auch „heute“ gehört dazu. Ein Mittagsmenü für Dienstag erscheint am Dienstag ohne Deploy, weil die Seite nach den Inhalten fragt, die jetzt gelten, in der Zeitzone der Seite.

## Wenn es kein Bundle gibt

Antwortet die Plattform nicht, hat die Seite kein Bundle, und die Seite antwortet mit **503**, nie mit 404. Ein Host wie Vercel behält dann die letzte gute Seite. [Mit fehlenden Inhalten umgehen]($docs.missing-content) zeigt, was du für diesen Fall baust.

Lies in `error.vue` keine Inhalte: Bei einem 503 gibt es kein Bundle, und auch die Fehlerseite würde scheitern.
