This guide changes the look of the components with CSS variables. At the end, the components use the colours of your site, and you know how to switch one component or all of them between a border and a fill.

## Before you start

The site has the components set up, see [Set up components]($docs.set-up-components). You need one CSS file that the site loads, for example `app/assets/css/main.css` listed under `css` in `nuxt.config.ts`.

## Use the colours of your site

The components read the shadcn tokens. A site that uses shadcn-vue has them already, and the components follow its theme with no further step.

A site without shadcn-vue sets the tokens it wants to change. Each colour must be a full colour value: `oklch(…)`, `hsl(…)` or hex.

```css [app/assets/css/main.css]
:root {
  --background: #fffdf8;
  --foreground: #1c1917;
  --muted: #f5f0e6;
  --muted-foreground: #78716c;
  --border: #e7e0d2;
  --primary: #166534;
  --primary-foreground: #ffffff;
  --radius: 0.5rem;
}
```

| Token | Used for |
| --- | --- |
| `--background`, `--card` | The fill of a quiet component. |
| `--foreground` | Text. |
| `--muted` | The fill of a tint component. |
| `--muted-foreground` | Secondary text, such as a caption. |
| `--border` | Borders. |
| `--primary`, `--primary-foreground` | Accents: the `idea` notice, a selected quiz answer, check marks in steps, the play button on hover. |
| `--ring` | The focus ring. Without it, `--primary`. |
| `--radius` | Rounded corners. |
| `--font-mono` | Code. |

Without a token, the component uses a neutral default.

::callout{type="warning" title="Old shadcn themes"}
Themes for Tailwind 3 store only numbers, such as `--muted: 210 40% 96%`. That is not a colour. Write the full value: `--muted: hsl(210 40% 96%)`.
::

## Border or fill

Every framed component is *quiet* (a border) or *tint* (a filled area). Notices and excerpts are tint, all others quiet.

````md preview
::note{title="Quiet" appearance="quiet"}
A border, no fill.
::

::note{title="Tint"}
A fill, no border.
::
````

`appearance="quiet"` or `appearance="tint"` changes one component. Cards follow their `cards` group.

For the whole site, set two tokens:

```css [app/assets/css/main.css]
:root {
  --ginko-surface: var(--muted);
  --ginko-surface-border: transparent;
}
```

This example makes every framed component tint.

## The notice colours

Each kind of notice has its own token:

```css [app/assets/css/main.css]
:root {
  --ginko-info: #1d4ed8;
  --ginko-warning: #b45309;
  --ginko-error: #b91c1c;
  --ginko-success: #15803d;
  --ginko-idea: #7c3aed;
}
```

## Dark mode

The components are dark where the site is dark: with `color-scheme: dark`, with the class `.dark`, or with `data-theme="dark"` on a parent element. A site that is only light stays light, also on a dark system.

With shadcn tokens, set the dark values under `.dark` as usual. The default colours of the components have a dark half of their own.

Code always sits on a dark panel, in both modes.

## Check that it works

Open a page with a notice and a card. Set `--ginko-warning` to a clear colour such as `magenta` and save. The sign of a `::warning` notice has that colour. Remove the line again.

## What stays stable

Style your own rules only against these names. They change only in a minor release, with an entry in the changelog. All other class names and `--ginko-*` variables are internal.

| Kind | Names |
| --- | --- |
| Tokens | `--ginko-surface`, `--ginko-surface-border`, `--ginko-tint` (the fill of tint, default `--muted`), `--ginko-info`, `--ginko-warning`, `--ginko-error`, `--ginko-success`, `--ginko-idea`, `--ginko-scroll-margin` (space above an API entry that a link jumps to, default `5rem`) |
| Code panel | `--ginko-code-frame`, `--ginko-code-bg`, `--ginko-code-fg`, `--ginko-code-muted`, `--ginko-code-hover` |
| Classes | `ginko-<tag>` on the outer element of each tag, for example `ginko-callout` or `ginko-card`. Exceptions: the code block is `ginko-code`, a Markdown image `ginko-img`, and `collapse` without `title` is `ginko-clip`. |
| Attribute | `data-appearance="quiet"` or `"tint"` on the outer element |
