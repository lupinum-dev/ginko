Diese Anleitung zeigt die Inhalte deiner Bausteine in einer Seite. Am Ende zeigt eine Seite die Werte eines Einzelstücks und die Liste einer Sammlung, mit Typen aus deiner Konfiguration.

## Bevor du beginnst

Die Seite hat ein Einzelstück und eine Sammlung. Die Beispiele nutzen ein Einzelstück `start` mit einem Titel und einem Text und eine Sammlung `prices` mit einem Titel, einem Preis und einem Ja/Nein-Wert. [Inhalte modellieren]($docs.model-your-content) zeigt, wie du Bausteine anlegst.

## Schritte

::steps
#### Ein Einzelstück lesen

`useGinko` liest einen Baustein über seinen Namen. Bei einem Einzelstück stehen die Felder in `data`:

```vue [app/pages/index.vue]
<script setup lang="ts">
const start = useGinko('start')
</script>

<template>
  <main>
    <h1>{{ start.data.title }}</h1>
  </main>
</template>
```

Du importierst `useGinko` nicht. Das Ginko-Modul stellt es in jeder Seite und Komponente bereit.

#### Einen formatierten Text zeigen

Ein Markdown-Feld ist kein String. Zeig es mit `<GinkoMarkdown>`:

```vue
<GinkoMarkdown :value="start.data.body" />
```

Die Komponente schreibt Überschriften, Listen und Links als HTML-Elemente. Im Browser läuft kein Parser, und sie fügt nie rohes HTML ein.

#### Eine Sammlung auflisten

Bei einer Sammlung stehen die Einträge in `items`. Jeder Eintrag hat eine `id` und seine Felder in `data`:

```vue
<script setup lang="ts">
const prices = useGinko('prices')
</script>

<template>
  <ul>
    <li v-for="item in prices.items" :key="item.id">
      {{ item.data.title }}
    </li>
  </ul>
</template>
```

Die Liste hat die Reihenfolge, die der Baustein setzt, und enthält nur die Einträge, die heute sichtbar sind.

#### Einen Wert im Script nutzen

`useGinko` gibt ein Ref zurück. Im Template schreibst du `start.data.title`. Im `<script>` hängst du `.value` an:

```ts
const start = useGinko('start')
const title = start.value.data.title
```

#### Das Ergebnis prüfen

Öffne die Seite. Sie zeigt den Titel des Einzelstücks und eine Zeile pro Eintrag. In der deutschen Fassung der Seite zeigt jeder Text seine deutsche Übersetzung. Ein Text ohne Übersetzung zeigt den Text der Hauptsprache.
::

## Die Typen kommen aus deiner Konfiguration

Dein Editor kennt die Felder jedes Bausteins. `item.data.` listet sie auf, und ein Feld, das der Baustein nicht hat, ist ein Fehler im Editor. Ein optionales Feld kann `undefined` sein.

Bekommt eine Komponente einen Eintrag als Prop, nimm den Typ `GinkoItem` mit dem Namen des Bausteins. Du importierst ihn nicht:

```vue [app/components/PriceRow.vue]
<script setup lang="ts">
defineProps<{ item: GinkoItem<'prices'> }>()
</script>

<template>
  <li>{{ item.data.title }}</li>
</template>
```
