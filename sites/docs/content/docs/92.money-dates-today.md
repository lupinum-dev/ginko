This guide turns stored values into text a visitor reads: "€12.50" and "October 8, 2026" in English, "12,50 €" and "8. Oktober 2026" in German. At the end, prices and dates follow the language of the page.

## Show a price

A money field holds `{ amount, currency }`, with the amount in minor units. `formatMoney` turns it into text. Import it from `@lupinum/ginko`:

```vue
<script setup lang="ts">
import { formatMoney } from '@lupinum/ginko'

const prices = useGinko('prices')
const { language } = useI18n()
</script>

<template>
  <ul>
    <li v-for="item in prices.items" :key="item.id">
      {{ item.data.title }}: {{ formatMoney(item.data.price, language) }}
    </li>
  </ul>
</template>
```

`language` is the language tag of the page, such as `en` or `de-AT`. The result follows it:

| Call | Result |
| --- | --- |
| `formatMoney({ amount: 1250, currency: 'EUR' }, 'en')` | `€12.50` |
| `formatMoney({ amount: 1250, currency: 'EUR' }, 'de')` | `12,50 €` |
| `formatMoney({ amount: 1250, currency: 'CHF' }, 'de-CH')` | `CHF 12.50` |
| `formatMoney({ amount: 39000, currency: 'EUR' }, 'en', { wholeWithoutMinor: true })` | `€390` |

Every space in the result is a no-break space, so a price never wraps to the next line.

## Show a date

A date field holds a text such as `2026-10-08`. `useI18n` has a `format` object that writes it in the language of the page:

```vue
<script setup lang="ts">
const { format } = useI18n()
</script>

<template>
  <time datetime="2026-10-08">{{ format.date('2026-10-08') }}</time>
</template>
```

| Call | English | German |
| --- | --- | --- |
| `format.date('2026-10-08')` | October 8, 2026 | 8. Oktober 2026 |
| `format.date('2026-10-08', 'short')` | 10/8/26 | 08.10.26 |
| `format.range('2026-06-20', '2026-06-21')` | June 20–21, 2026 | 20.–21. Juni 2026 |

The second argument of `format.date` is `'short'`, `'medium'`, `'long'` (the default) or `'full'`. The server and the browser write the same text.

## Show what is true today

`useGinkoToday` returns today's date as `YYYY-MM-DD`, in the time zone of the site:

```vue
<script setup lang="ts">
const route = useRoute()
const post = useGinkoEntry('news', () => route.params.slug)
const today = useGinkoToday()
const isToday = computed(() => post.value.data.date === today.value)
</script>

<template>
  <p v-if="isToday">This post is from today.</p>
</template>
```

The value moves on after midnight without a reload of the page. Compare with it, and not with `new Date()`: the visitor's computer may be in another time zone than the site.
