This guide moves the fixed texts of a site out of the templates and into one file per language. Fixed texts are the words of the layout: navigation, button labels, "Read more". The content of bricks is not part of them.

At the end, a page shows its fixed texts in the language of the reader, and a check lists each text that still has no translation.

## Steps

::steps
#### Create one file per language

The files live in `i18n/`, next to `nuxt.config.ts`. The name is the language code:

```json [i18n/en.json]
{
  "nav": { "about": "About us" },
  "weekOf": "Week of {date}",
  "dishes": "{count, plural, one {# dish} other {# dishes}}"
}
```

```json [i18n/de.json]
{
  "nav": { "about": "Über uns" },
  "weekOf": "Woche ab {date}",
  "dishes": "{count, plural, one {# Gericht} other {# Gerichte}}"
}
```

Nesting groups keys. A key itself has no dot.

#### Show a text with t

```vue
<script setup lang="ts">
const { t } = useI18n()
</script>

<template>
  <h1>{{ t('nav.about') }}</h1>
  <p>{{ t('weekOf', { date: 'October 5' }) }}</p>
  <p>{{ t('dishes', { count: 3 }) }}</p>
</template>
```

- `t('nav.about')` reads `about` inside `nav`.
- A name in curly braces is a parameter. `t('weekOf', { date: 'October 5' })` gives "Week of October 5".
- `plural` picks a form by a number. `t('dishes', { count: 1 })` gives "1 dish", and with `count: 3` it gives "3 dishes".

Your editor knows the keys. A key that is in no file is an error in the editor.

#### Check the result

Open the page in each language. Then run the check:

```bash
npx ginko-i18n check
```

It lists each key that a language does not have:

```text
error missing de consent i18n/en.json:5: Missing translation
1 errors, 0 warnings
```

The dev server reads the files again when you save them.
::

## A missing text

A key that is missing in one language shows the text of the main language. The dev server warns about it at the start.

## A text with a link

Write a tag in the message, and fill it with `<I18nT>`:

```json [i18n/en.json]
{
  "consent": "I accept the <link>privacy policy</link>."
}
```

```vue
<script setup lang="ts">
const { localePath } = useI18n()
</script>

<template>
  <I18nT k="consent">
    <template #link="{ text }">
      <NuxtLink :to="localePath('/privacy')">{{ text }}</NuxtLink>
    </template>
  </I18nT>
</template>
```

The slot has the name of the tag and receives the words between the tags. Translators can move the link inside the sentence, and no HTML is in the message.
