Ein Template ist eine vollständige Seite als Ausgangspunkt: Seiten, Beispielinhalte, ein Design mit hellem und dunklem Modus und zwei oder mehr Sprachen. Jedes Template liest seine Inhalte aus Dateien und läuft deshalb ohne Konto.

```bash
npm create ginko@latest meine-seite -- --template <name>
```

Schreib die Optionen nach `--`, sonst behält npm sie für sich. pnpm, yarn und bun nehmen denselben Befehl.

## Optionen

| Option | Werte | Standard |
| --- | --- | --- |
| `--template <name>` | Der Name eines Templates oben. | Eine kleine Seite mit einer Seite, wie im [Schnellstart]($docs.getting-started). |
| `--locales <kürzel>` | Die Sprachen, die bleiben, durch Kommas getrennt. Die erste ist die Hauptsprache. | Alle Sprachen des Templates. |
| `-h`, `--help` | | |

```bash
npm create ginko@latest meine-seite -- --template nonprofit --locales de,fr
```

Das behält Deutsch und Französisch und macht Deutsch zur Hauptsprache. Die deutschen Adressen haben dann kein Präfix, die französischen beginnen mit `/fr`.

Ohne `--template` nimmt `--locales` `en` oder `de`, nur eines davon.

`--preset` und `--locale` sind die älteren Formen dieser Optionen. Sie gehen noch und geben einen Hinweis aus.

## Was der Befehl tut

1. Er kopiert das Template in den neuen Ordner. Der Ordner muss neu oder leer sein.
2. Er behält die Sprachen aus `--locales` und entfernt die Inhaltsdateien, Übersetzungstexte und Adressen der anderen.
3. Er verschiebt die Daten kommender Beispieleinträge, etwa von Veranstaltungen und Hinweisen, in diese Woche, damit die Seite sie zeigt.
4. Er setzt die Id der Seite (`site` in `ginko.config.ts`) aus dem Ordnernamen.
5. Er schreibt eine Datei `.env` mit einem neuen `NUXT_APP_SECRET`. Das Secret signiert die Adressen der Teilen-Karten.

Der Befehl installiert nichts. Führe im neuen Ordner `npm install` und `npm run dev` aus.

## Nach dem Anlegen

Die `README.md` im neuen Ordner ist das Handbuch dieses Templates. Sie nennt die Datei hinter jedem Teil der Seite, und ihr Abschnitt „Make it yours“ sagt, wie du die Beispielinhalte ersetzt. Die README ist englisch.

- [Eine Sprache hinzufügen]($docs.add-a-language) ergänzt eine weitere Sprache.
- [single und collection]($docs.bricks) erklärt die Inhaltstypen in `ginko.config.ts`.
- [Auf Vercel veröffentlichen]($docs.deploy-to-vercel) stellt die Seite online.
