title: Einen Sprachwechsel bauen

---

Diese Anleitung baut einen Sprachwechsel: eine Reihe von Links, die von einer Seite zur selben Seite in jeder anderen Sprache führen. Am Ende führt der Wechsel auf einem Eintrag zum übersetzten Eintrag, auch wenn seine Adresse in jeder Sprache anders ist.

Jedes Template hat einen Sprachwechsel. Bau deinen eigenen, wenn du ohne Template beginnst oder eine andere Form willst.

## Schritte

::steps
#### Die alternates lesen

`useI18n` liefert `alternates`: die aktuelle Seite in jeder Sprache der Seite.

```vue [app/components/LanguageSwitch.vue]
<script setup lang="ts">
const { alternates } = useI18n()
</script>

<template>
  <nav aria-label="Sprache">
    <NuxtLink
      v-for="a in alternates"
      :key="a.code"
      :to="a.path"
      :hreflang="a.language"
      :aria-current="a.current ? 'page' : undefined"
    >
      {{ a.name }}
    </NuxtLink>
  </nav>
</template>
```

Jeder Eintrag von `alternates` hat diese Werte:

| Wert | Bedeutung |
| --- | --- |
| `code` | Das Kürzel der Sprache, zum Beispiel `de` |
| `language` | Ihr Sprach-Tag, zum Beispiel `de-AT` |
| `name` | Ihr Name in der Sprache selbst, zum Beispiel „Deutsch“ |
| `path` | Die Adresse der aktuellen Seite in dieser Sprache |
| `current` | `true` für die Sprache der aktuellen Seite |
| `translated` | `false`, wenn die Seite in dieser Sprache keine Fassung hat |

#### Ihn ins Layout setzen

```vue [app/app.vue]
<template>
  <LanguageSwitch />
  <NuxtPage />
</template>
```

#### Das Ergebnis prüfen

1. Auf einer festen Seite mit übersetzten Pfaden führt der Wechsel von `/about` zu `/de/ueber-uns`.
2. Auf einem Eintrag führt er zum Eintrag in der anderen Sprache, zum Beispiel `/de/neuigkeiten/wir-haben-geoeffnet`.
::

## Eine Seite ohne Übersetzung

Hat die aktuelle Seite in einer Sprache keine Fassung, ist `translated` `false` und `path` die Startseite dieser Sprache. Sag das, oder verbirg den Link:

```vue
<NuxtLink v-for="a in alternates" :key="a.code" :to="a.path" :hreflang="a.language">
  {{ a.name }}<span v-if="!a.translated"> (Startseite)</span>
</NuxtLink>
```

## Was du ohne Code bekommst

Die Links zwischen den Sprachen für Suchmaschinen (`hreflang`) und das `lang`-Attribut der Seite kommen aus denselben Daten. Du schreibst dafür nichts.
