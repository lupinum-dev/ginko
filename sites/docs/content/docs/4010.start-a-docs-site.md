This guide creates a documentation site with the docs kit `@lupinum/ginko-docs`. At the end, you have a site with search, navigation, light and dark mode, and your first own page in it. These docs are built the same way.

A kit is a package that brings a whole kind of site. You write the pages as Markdown files. The kit adds everything around them:

- a header with search, a language menu and a light/dark switch,
- the side navigation with groups, breadcrumbs, a table of contents and links to the page before and after,
- the [components]($docs.components) for notices, tabs, steps and code,
- "Copy page" as Markdown, "Edit this page" and "Report an issue",
- every page as Markdown for AI agents, and an MCP endpoint, see [Serve pages to AI agents]($docs.pages-for-agents).

## Before you start

You need Node.js 22.18 or newer and npm, pnpm or bun.

## Steps

::steps
#### Create the site

```bash
npm create ginko@latest my-docs -- --template docs
```

The template is the documentation of a made-up library, in English and German. `--locales en` keeps English only.

#### Install and start

```bash
cd my-docs
npm install
npm run dev
```

Open `http://localhost:3000`. You see the start page. `/docs` opens the first docs page.

#### Add a page

Each file in `content/docs/` is one page. The number in the file name sets the order. The address comes from the rest of the name: this page is `/docs/rate-limits`.

```markdown [content/docs/12.rate-limits.md]
---
title: Rate limits
description: How many requests the API takes per minute, and what the client does when you reach the limit.
---

The API takes 600 requests per minute for each API key.

## When you reach the limit

The API answers with status 429.

::callout{type="info" title="Good to know"}
Reading a list counts as one request per page.
::
```

`title` and `description` are required. The page appears at the end of the navigation, in the group of the page before it.

#### Place the page in the navigation

The frontmatter sets where and how the page shows:

```markdown [content/docs/12.rate-limits.md]
---
title: Rate limits
description: How many requests the API takes per minute, and what the client does when you reach the limit.
navTitle: Limits
section: Limits and errors
icon: lucide:gauge
badge: New
---
```

| Field | Effect |
| --- | --- |
| `navTitle` | A short title for the navigation, the breadcrumbs and the links to the page before and after. |
| `section` | Starts a group in the navigation with this heading. The pages after it belong to it until the next `section`. |
| `tab` | Starts a tab above the navigation, for example "Guide" and "Reference". Pages follow the tab before them. Four or more tabs show as a menu that names the active tab. |
| `parent` | Nests the page under another one: `parent: docs/<name>`. |
| `icon` | An Iconify name, before the title in the navigation. Set it in the main language only. |
| `badge` | A short label after the title. |

The Lucide icons are installed. Another icon set works after `npm install -D @iconify-json/<set>`.

#### Translate the page

A translation is a file with the language code before `.md`. It holds only the fields that have a translation, and the text:

```markdown [content/docs/12.rate-limits.de.md]
---
title: Limits
description: Wie viele Anfragen die API pro Minute annimmt.
---

Die API nimmt 600 Anfragen pro Minute und API-Schlüssel an.
```

A page without a translation does not show in that language.

#### Set the header and the footer

The options of the kit go into `app/app.config.ts`. The texts of links come from the message files, so each language has its own:

```ts [app/app.config.ts]
export default defineAppConfig({
  docs: {
    logo: { light: '/logo.svg', dark: '/logo-dark.svg' },
    nav: [{ id: 'status', href: 'https://status.example.com' }],
    banner: { id: 'v2', href: '/docs/upgrading-to-v2' },
    repository: { url: 'https://github.com/me/docs', branch: 'main' },
    footer: { links: [{ id: 'source', href: 'https://github.com/me/docs' }] },
  },
})
```

```json [i18n/en.json]
{
  "docs": {
    "nav": { "status": "Status" },
    "banner": { "v2": "Version 2 is out." },
    "footer": { "source": "Source code" }
  }
}
```

Each `id` picks a message. [Docs site reference]($docs.docs-site-reference#options) lists all options.
::

## Check that it works

- `/docs/rate-limits` shows the page, and the navigation shows "Limits" with the badge "New" under the heading "Limits and errors".
- The header has the link "Status", and a banner above it says "Version 2 is out."
- Under the page, "Edit this page" opens the file in your repository.
- `npm run check` ends with `OK: schema and links are fine.` The template sets `linkCheck: { anchors: 'error' }`, so a link to a heading that does not exist stops the check.

## Start without the template

To add the kit to an empty Nuxt project, install the packages and write two files:

```bash
npm install @lupinum/ginko @lupinum/ginko-content @lupinum/ginko-i18n @lupinum/ginko-docs
```

```ts [ginko.config.ts]
import { defineSite } from '@lupinum/ginko'
import { components, docsCollection } from '@lupinum/ginko-docs/config'

const locales = ['en', 'de'] as const

export default defineSite({
  site: 'my-docs',
  name: 'My docs',
  url: 'https://docs.example.com',
  timeZone: 'Europe/Vienna',
  locales,
  currency: 'EUR',
  pages: { home: { en: '/', de: '/de' } },
  components,
  bricks: { docs: docsCollection({ locales }) },
})
```

```ts [nuxt.config.ts]
import ginko from './ginko.config.ts'

export default defineNuxtConfig({
  compatibilityDate: '2026-10-01',
  extends: ['@lupinum/ginko-docs'],
  modules: ['@lupinum/ginko/nuxt'],
  ginko,
})
```

Then add pages in `content/docs/`. Without a start page, `/` opens the first docs page.

## The start page

`docsHome()` adds a start page from one file. The frontmatter fills the top of the page and the cards. The text below follows them and can use every component.

```ts [ginko.config.ts]
import { components, docsCollection, docsHome, homePages } from '@lupinum/ginko-docs/config'

// …
  pages: { home: homePages({ locales }) },
  bricks: { home: docsHome(), docs: docsCollection({ locales }) },
```

```markdown [content/home.md]
---
title: Docs for my library.
description: One sentence on what it does.
install: npm install my-library
links:
  - label: Get started
    href: $docs.introduction
  - label: GitHub
    href: https://github.com/me/lib
features:
  - icon: lucide:zap
    title: Fast
    description: Why it is fast.
    href: $docs.speed
---
```

`install` shows a command with a copy button. `links` holds up to two buttons; the first one is the main one. A page `app/pages/index.vue` of your own wins over the start page.
