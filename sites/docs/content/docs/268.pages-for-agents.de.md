KI-Agenten lesen Markdown besser als HTML. Eine Ginko-Seite liefert beides aus denselben Inhalten, ohne zusätzliche Arbeit. Diese Anleitung zeigt, was Agenten bekommen, wie du ihnen die Seite beschreibst und wie du es ausschaltest.

## Was jede Seite ausliefert

| Adresse | Inhalt |
| --- | --- |
| `<seite>.md` | Ein Eintrag als Markdown: `/news/opening.md` ist die Seite `/news/opening`. |
| `/llms.txt` | Der Name der Seite, eine Beschreibung und eine Liste ihrer Einträge mit Links zu deren Markdown. |
| `/llms-full.txt` | Der Text all dieser Einträge in einer Datei. |

Ein Eintrag hat eine Markdown-Adresse, wenn sein Baustein eine Route hat. Die Listen enthalten die Einträge der Hauptsprache.

## Schritte

::steps
#### Die Seite für Agenten beschreiben

```ts [ginko.config.ts]
export default defineSite({
  // …
  agents: { description: 'Neuigkeiten und Preise des Gasthauses zur Linde.' },
})
```

Ohne die Einstellung zeigt `llms.txt` die `seo.description`.

#### Das Ergebnis prüfen

```bash
curl https://www.linde.example/llms.txt
```

```markdown
# Gasthaus zur Linde

> Neuigkeiten und Preise des Gasthauses zur Linde.

## News

- [We are open](https://www.linde.example/news/opening.md)
```

Frag dann nach einem Eintrag:

```bash
curl -i https://www.linde.example/news/opening.md
```

Die Antwort hat `content-type: text/markdown` und den Text des Eintrags.
::

## Wie ein Agent das Markdown findet

Die HTML-Seite nennt ihre Markdown-Fassung in einem Header:

```text
link: </news/opening.md>; rel="alternate"; type="text/markdown"
```

Die normale Adresse antwortet immer mit HTML, egal was die Anfrage verlangt. Nur die Adresse mit `.md` antwortet mit Markdown. Der Cache eines Hosters hält eine Fassung pro Adresse. So bleiben Besucher und Agenten getrennt.

Eine Markdown-Adresse ohne Eintrag antwortet mit 404, ebenfalls in Markdown, und schlägt ähnliche Seiten vor.

## Ausschalten

```ts [ginko.config.ts]
agents: { enabled: false },
```

`/llms.txt`, `/llms-full.txt` und jede `.md`-Adresse antworten dann mit 404, und die Seiten haben keinen `link`-Header.

## Deine eigene Datei

Eine Datei `public/llms.txt` ersetzt die erzeugte. Dasselbe gilt für `public/robots.txt`.

## Agenten, die schreiben

Auf der Plattform kann ein Agent mit einem Schlüssel auch Inhalte schreiben. Mit `agents: { review: true }` wartet alles, was so ein Agent schreibt, auf ein Ja einer Inhaberin. [Die Plattform für Inhaber]($docs.platform-for-owners) erklärt es.
