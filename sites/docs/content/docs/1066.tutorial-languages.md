In [chapter 3]($docs.tutorial-blog) the site got a blog. This chapter adds German as a second language. At the end, `http://localhost:3000/de` shows the German home page, and a switch in the header leads to the same page in the other language.

English stays the main language. Its addresses have no prefix; the German ones start with `/de`.

## Steps

::steps
#### Add the language and its addresses

In `ginko.config.ts`, add `de` to `locales` and give every address a German version:

```ts [ginko.config.ts]
import { collection, defineSite, f, single } from '@lupinum/ginko'
import { authors, posts } from '@lupinum/ginko/basics'

export default defineSite({
  site: 'my-site',
  name: 'Studio Nord',
  url: 'https://example.com',
  timeZone: 'Europe/Vienna',
  week: { firstDay: 'mo', workdays: ['mo', 'tu', 'we', 'th', 'fr'] },
  locales: ['en', 'de'],
  currency: 'EUR',
  pages: {
    home: { en: '/', de: '/de' },
    blog: { en: '/blog', de: '/de/blog' },
  },
  bricks: {
    home: single({
      label: 'Home page',
      source: 'files',
      fields: {
        title: f.text('Title'),
        body: f.markdown('Text', { profile: 'basic' }),
      },
    }),
    pages: collection({
      label: 'Pages',
      source: 'files',
      max: 50,
      order: 'manual',
      route: { en: '/[slug]', de: '/de/[slug]' },
      fields: {
        title: f.text('Title'),
        slug: f.slug('Address', { from: 'title' }),
        summary: f.longtext('Summary', { optional: true }),
        body: f.markdown('Text', { profile: 'basic' }),
      },
    }),
    posts: posts({ source: 'files', route: { en: '/blog/[slug]', de: '/de/blog/[slug]' } }),
    authors: authors({ source: 'files' }),
  },
})
```

Each address of a language other than the main one includes its prefix. The Vue pages need no change: Nuxt serves `app/pages/blog/index.vue` at `/blog` and at `/de/blog`. To give an address German words, such as `/de/neuigkeiten`, see [Translate addresses]($docs.translate-addresses).

#### Translate the content

A translation is a second file with the same name plus the language code:

```markdown [content/home.de.md]
---
title: Studio Nord
---

Wir gestalten Bücher und Plakate in Wien. Dieser Text steht in `content/home.de.md`.
```

```markdown [content/pages/1.about.de.md]
---
title: Über uns
slug: ueber-uns
summary: Zwei Gestalter, eine Werkstatt.
---

Studio Nord sind Anna und Jonas. Wir arbeiten in einer früheren Druckerei im 7. Bezirk.
```

```markdown [content/pages/2.contact.de.md]
---
title: Kontakt
slug: kontakt
summary: Schreiben Sie uns.
---

Schreiben Sie an hello@example.com. Wir antworten innerhalb von zwei Tagen.
```

```markdown [content/posts/hello.de.md]
---
title: Grüße aus der Werkstatt
slug: gruesse-aus-der-werkstatt
---

Die Seite ist online. Hier schreiben wir über neue Arbeiten.
```

A translation holds only the fields that change with the language. The date and the authors of a post stay in `hello.md`. `slug` gives the German page its own address: `/de/ueber-uns`. Without it, the slug comes from the file name.

The post "A new poster series" has no German file. An entry with a page appears only in the languages it is translated into, so the German blog lists one post. [Missing translations]($docs.missing-translations) shows the other choice: show the main language instead.

#### Translate the fixed texts

"Home" and "Blog" in the menu are not content. They are fixed texts of the site, and they live in one file per language in `i18n/`:

```json [i18n/en.json]
{
  "nav": { "home": "Home", "blog": "Blog", "language": "Language" }
}
```

```json [i18n/de.json]
{
  "nav": { "home": "Start", "blog": "Blog", "language": "Sprache" }
}
```

#### Add the language switch

```vue [app/app.vue]
<script setup lang="ts">
const pages = useGinko('pages')
const path = useGinkoPath()
const { t, alternates } = useI18n()
</script>

<template>
  <header>
    <nav>
      <NuxtLink :to="path('home')">{{ t('nav.home') }}</NuxtLink>
      <NuxtLink :to="path('blog')">{{ t('nav.blog') }}</NuxtLink>
      <NuxtLink v-for="page in pages.items" :key="page.id" :to="page.url">{{ page.data.title }}</NuxtLink>
    </nav>
    <nav :aria-label="t('nav.language')">
      <NuxtLink v-for="a in alternates" :key="a.code" :to="a.path" :hreflang="a.language" :aria-current="a.current ? 'page' : undefined">
        {{ a.code.toUpperCase() }}
      </NuxtLink>
    </nav>
  </header>
  <NuxtPage />
</template>

<style>
body { font-family: system-ui, sans-serif; line-height: 1.5; max-width: 40rem; margin: 2rem auto; padding: 0 1rem; }
header { display: flex; justify-content: space-between; }
nav { display: flex; gap: 1rem; }
</style>
```

- `path('home')` is the address of the home page in the current language: `/` or `/de`.
- `t('nav.home')` reads the text from the file of the current language.
- `alternates` is the current page in every language. On `/about`, the German link leads to `/de/ueber-uns`.

In `app/pages/blog/index.vue`, replace the heading "Blog" with the fixed text too:

```vue [app/pages/blog/index.vue]
<script setup lang="ts">
const posts = useGinko('posts')
const { t, format } = useI18n()
</script>

<template>
  <main>
    <h1>{{ t('nav.blog') }}</h1>
    <article v-for="post in posts.items" :key="post.id">
      <h2><NuxtLink :to="post.url">{{ post.data.title }}</NuxtLink></h2>
      <time :datetime="post.data.date">{{ format.date(post.data.date) }}</time>
      <p v-if="post.data.description">{{ post.data.description }}</p>
    </article>
  </main>
</template>
```
::

## Check that it works

- Open `http://localhost:3000/de`. The menu reads "Start", "Blog", "Über uns", "Kontakt", and the text is German.
- Open `http://localhost:3000/about` and click DE. The address is `/de/ueber-uns`.
- Open `http://localhost:3000/de/blog`. It lists "Grüße aus der Werkstatt" with the date "12. Oktober 2026".
- In the page source of a German page, the `<html>` tag has `lang="de"`. ginko-i18n sets it, together with the links that tell search engines about the other language.
