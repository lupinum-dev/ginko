Diese Anleitung baut ein Suchfeld in eine Seite ein. Am Ende tippt ein Besucher ein Wort und bekommt Links zu den Einträgen und Abschnitten, die es enthalten. Die Suche läuft im Browser und braucht keinen Dienst.

## Was Ginko bereitstellt

Ginko baut einen Suchindex pro Sprache und liefert ihn unter `/__ginko/search/<sprache>.json` aus. Er enthält einen Datensatz für den Anfang jedes Eintrags und einen für jeden Abschnitt unter einer `##`- oder `###`-Überschrift. Nur Einträge mit eigener Adresse stehen darin.

Du schreibst das Feld und die Liste der Ergebnisse.

## Schritte

::steps
#### Die Suchkomponente ergänzen

```vue [app/components/SiteSearch.vue]
<script setup lang="ts">
import type { SearchHit, SearchIndex, SearchIndexJson } from '@lupinum/ginko/search'

const { locale } = useI18n()
const query = ref('')
const hits = ref<SearchHit[]>([])
const indexes = new Map<string, SearchIndex>()

watch(query, async (text) => {
  // Suchmaschine und Index erst laden, wenn jemand sucht.
  const { loadIndex, search } = await import('@lupinum/ginko/search')
  let index = indexes.get(locale.value)
  if (!index) {
    index = await loadIndex(await $fetch<SearchIndexJson>(`/__ginko/search/${locale.value}.json`))
    indexes.set(locale.value, index)
  }
  hits.value = search(index, text, { limit: 8 })
})
</script>

<template>
  <input v-model="query" type="search" aria-label="Suche">
  <ul>
    <li v-for="hit in hits" :key="hit.id">
      <NuxtLink :to="hit.url">{{ hit.heading ?? hit.title }}</NuxtLink>
      <p>{{ hit.excerpt }}</p>
    </li>
  </ul>
</template>
```

Die Komponente lädt den Such-Code und den Index erst, wenn ein Besucher tippt. Seiten ohne Suche bleiben klein.

#### Sie auf eine Seite setzen

```vue [app/pages/search.vue]
<template>
  <main>
    <SiteSearch />
  </main>
</template>
```

#### Das Ergebnis prüfen

Öffne `/search` und tippe ein Wort aus einem deiner Einträge. Mit einem Eintrag „We are open“, der einen Abschnitt „Opening hours“ mit dem Satz „We open the garden at noon“ hat:

- „garden“ findet den Abschnitt. Sein Link ist `/news/opening#opening-hours`, und der Auszug ist der Satz.
- „opend“, mit einem Tippfehler, findet „Opening hours“ und „We are open“.
::

## Was ein Treffer enthält

| Wert | Bedeutung |
| --- | --- |
| `url` | Die Adresse des Eintrags, mit dem Anker seines Abschnitts |
| `title` | Der Titel des Eintrags |
| `heading` | Die Überschrift des Abschnitts, wenn der Treffer ein Abschnitt ist |
| `excerpt` | Der Text um das Wort herum |
| `score` | Wie gut der Treffer passt |

## Wie die Suche vergleicht

- Sie findet ein Wort über seinen Anfang und verzeiht kleine Tippfehler.
- In Deutsch, Englisch, Französisch, Italienisch, Spanisch, Niederländisch und Portugiesisch findet sie andere Formen eines Wortes: „Gerichte“ findet „Gericht“.
- Akzente spielen keine Rolle: „cafe“ findet „café“.
- Jede Sprache hat ihren eigenen Index. Ein Besucher auf einer deutschen Seite durchsucht die deutschen Texte.
