Diese Anleitung gibt jeder Seite die Texte und das Bild, die ein Suchergebnis oder eine Link-Vorschau zeigt. Am Ende hat jede Seite ihren eigenen Titel und ihre Beschreibung, und ein Link auf sie in einem Chat zeigt eine Karte.

## Schritte

::steps
#### Die Vorgaben der Seite setzen

```ts [ginko.config.ts]
export default defineSite({
  site: 'linde',
  name: 'Gasthaus zur Linde',
  // …
  seo: {
    titleTemplate: '%s · Gasthaus zur Linde',
    description: 'Landgasthaus mit Garten.',
  },
})
```

`titleTemplate` umschließt den Titel jeder Seite. `%s` steht für diesen Titel. `description` ist die Beschreibung jeder Seite, die keine eigene setzt.

#### useGinkoSeo auf jeder Seite aufrufen

```vue [app/pages/news/[slug].vue]
<script setup lang="ts">
const route = useRoute()
const post = useGinkoEntry('news', () => route.params.slug)

useGinkoSeo(() => ({
  title: post.value.data.title,
  description: 'Neuigkeiten aus dem Gasthaus zur Linde.',
  image: post.value.data.photo?.url,
  type: 'article',
}))
</script>
```

Gib eine Funktion an, damit die Werte dem Inhalt folgen. Auf einer Seite ohne Eigenes rufst du `useGinkoSeo({})` auf: Die Seite hat dann den Namen der Seite als Titel und die Beschreibung der Seite.

Eine Seite, die `useGinkoSeo` nicht aufruft, hat keinen Titel.

#### Das Ergebnis prüfen

Öffne die Seite und sieh dir ihren Quelltext an. Für den Eintrag „We are open“:

```html
<title>We are open · Gasthaus zur Linde</title>
<meta name="description" content="Neuigkeiten aus dem Gasthaus zur Linde.">
<meta property="og:title" content="We are open">
<meta property="og:type" content="article">
<meta property="og:image" content="https://linde.example/img/kitchen.jpg">
<meta name="twitter:card" content="summary_large_image">
<link rel="canonical" href="https://linde.example/news/opening">
```

Der Canonical-Link und die `hreflang`-Links kommen von selbst, aus `url` und den Sprachen der Seite.
::

## Ein Titel ohne die Vorlage

Die Startseite hat oft einen vollständigen eigenen Titel. Schalte die Vorlage für sie aus:

```ts
useGinkoSeo({ title: 'Gasthaus zur Linde in Hallstatt', titleTemplate: false })
```

Der Titel ist dann genau „Gasthaus zur Linde in Hallstatt“.

## Die Einstellungen

| Einstellung | Bedeutung | Standard |
| --- | --- | --- |
| `title` | Der Titel der Seite. | der Name der Seite |
| `description` | Der Text unter dem Titel in einem Suchergebnis. | `seo.description` |
| `image` | Das Bild einer Link-Vorschau: ein Pfad unter `public/`, eine volle Adresse oder `{ url, width, height, alt }`. | `seo.image` |
| `type` | `'website'` oder `'article'`. | `'website'` |
| `noindex` | `true` hält die Seite aus Suchmaschinen heraus. | indexiert |
| `jsonLd` | Strukturierte Daten, siehe [Strukturierte Daten ergänzen]($docs.structured-data). | keine |

## Erzeugte Teilen-Karten

Jedes Template kommt mit `nuxt-og-image`. Jede Seite bekommt dann eine erzeugte Karte mit 1200 mal 600 Pixeln: der Name der Seite, der Titel und die Beschreibung der Seite, auf der Markenfarbe `seo.color`. Das Bild der Seite, wenn sie eines hat, kommt in die Karte.

```ts [ginko.config.ts]
seo: {
  color: '#1e4032',
  organization: { logo: '/logo.png' },
},
```

Die Karte braucht nichts auf der Seite: `useGinkoSeo` gibt ihr Titel und Beschreibung. Auf einem Server braucht die Seite die Variable `NUXT_APP_SECRET`, siehe [Auf Vercel veröffentlichen]($docs.deploy-to-vercel).

Eine Seite ohne `nuxt-og-image` zeigt das Bild, das du angibst, oder `seo.image`.

## Eine Seite aus Suchmaschinen heraushalten

Für eine Seite aus `pages`, etwa eine Danke-Seite nach einem Formular, nennst du ihren Schlüssel in der Konfiguration:

```ts [ginko.config.ts]
pages: { thanks: { en: '/thanks', de: '/de/danke' } },
seo: { noindex: ['thanks'] },
```

Die Seite verlässt die Sitemap und antwortet in jeder Sprache mit `x-robots-tag: noindex`.
