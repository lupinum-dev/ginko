A template is a complete site to start from: pages, sample content, a design with light and dark mode, and two or more languages. Every template reads its content from files, so it runs without an account.

```bash
npm create ginko@latest my-site -- --template <name>
```

Write the options after `--`. Without it, npm keeps them for itself. pnpm, yarn and bun take the same command.

## Options

| Option | Values | Default |
| --- | --- | --- |
| `--template <name>` | The name of a template above. | A small site with one page, as in [Quick start]($docs.getting-started). |
| `--locales <codes>` | The languages to keep, separated by commas. The first one is the main language. | All languages of the template. |
| `-h`, `--help` | | |

```bash
npm create ginko@latest my-site -- --template nonprofit --locales de,fr
```

This keeps German and French and makes German the main language. Its addresses then have no prefix, and the French ones start with `/fr`.

Without `--template`, `--locales` takes `en` or `de`, one at a time.

`--preset` and `--locale` are the older forms of these options. They still work and print a note.

## What the command does

1. It copies the template into the new folder. The folder must be new or empty.
2. It keeps the languages of `--locales` and removes the content files, message files and addresses of the others.
3. It moves the dates of upcoming sample entries, such as events and notices, to this week, so the site shows them.
4. It sets the id of the site (`site` in `ginko.config.ts`) from the folder name.
5. It writes a `.env` file with a new `NUXT_APP_SECRET`. The secret signs the addresses of the share cards.

The command installs nothing. Run `npm install` and `npm run dev` in the new folder.

## After you created the site

The `README.md` in the new folder is the manual of that template. It names the file behind every part of the site, and its section "Make it yours" says how to replace the sample.

- [Add a language]($docs.add-a-language) adds one more language.

- [Deploy to Vercel]($docs.deploy-to-vercel) puts the site online.
