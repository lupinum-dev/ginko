This recipe adds events to a site that runs and was made from a template, for example the `starter` of the [Quick start]($docs.getting-started). At the end, `/events` lists the coming events, each event has its own page with date, time, place, price and a booking link, and search engines get the event data. An event leaves the site after its last day.

The template `events` has the finished feature. You copy its files into your site. For a site you built by hand, write the pages yourself; [Give entries their own pages]($docs.entry-pages) shows how.

## What you add

| Part | Where |
| --- | --- |
| Brick | `events` from `@lupinum/ginko/patterns`, in `ginko.config.ts` |
| Content | `content/events/<n>.<slug>.md` |
| Pages | `app/pages/events/index.vue` (the list) and `events/[slug].vue` (an event) |
| Code | `app/components/event/` (the booking actions, the next events for another page), `app/composables/useEvents.ts` |
| Texts | `i18n/events/<language>.json` |

## Steps

::steps
#### Get the files

In your site's folder, create a copy of the template `events` next to it, in the languages of your site. It needs no `npm install`:

```bash
npm create ginko@latest ../events-files -- --template events --locales en,de
```

#### Copy the events into your site

```bash
mkdir -p app/components/event
cp ../events-files/app/components/event/Actions.vue ../events-files/app/components/event/Upcoming.vue app/components/event/
cp ../events-files/app/composables/useEvents.ts app/composables/
cp -R ../events-files/app/pages/events app/pages/
cp -R ../events-files/i18n/events i18n/
```

Copy only these two components. The other files in `app/components/event/` of the template belong to its own design and to its programme.

#### Add the brick and the page

```ts [ginko.config.ts]
import { events, legal, notices, site } from '@lupinum/ginko/patterns'

export default defineSite({
  // …
  pages: {
    home: localized('/'),
    events: localized('/events'),
  },
  entries: {
    events: localized('/events/[slug]'),
  },
  bricks: {
    // … the bricks you have
    events: events(),
  },
})
```

The page key must stay `events`, because the pages live in `app/pages/events/`. The times use `timeZone` and the prices `currency` of `ginko.config.ts`; every template has both.

#### Write an event

```markdown [content/events/1.reading.md]
---
title: Reading at the city library
when:
  from: 2026-12-10
  to: 2026-12-10
start: '19:00'
end: '20:30'
location: City library, Main hall
price: 8
booking: https://example.com/tickets
---

I read from the new catalogue in German and English, then we talk about translating names.
```

```markdown [content/events/1.reading.de.md]
---
title: Lesung in der Stadtbibliothek
slug: lesung-in-der-stadtbibliothek
location: Stadtbibliothek, Großer Saal
---

Ich lese aus dem neuen Katalog auf Deutsch und Englisch, danach sprechen wir über das Übersetzen von Namen.
```

Pick a date in the future: an event shows until the day `when.to`. `price` is in the currency of the site, so `8` is €8. Write the times in quotes. More fields: `online` (a link for an online event), `bookingUntil` (the last day the booking link shows), `soldOut: true` (shows "fully booked" instead of the link) and `image`.

#### Put the events into the menu

```ts [app/app.config.ts]
nav: [{ entry: 'pages/about' }, { page: 'events', label: { en: 'Events', de: 'Veranstaltungen' } }, { entry: 'pages/contact' }],
```
::

## Check that it works

- Open `http://localhost:3000/events`. The event is listed with its date.
- Click it. The page shows the weekday and date, "19:00–20:30", the place, "€8 per person" and the link "Book a place".
- Open `http://localhost:3000/de/events`. It lists "Lesung in der Stadtbibliothek".
- Run `npm run check`. It prints `OK: schema and links are fine.`

Then delete the folder `../events-files`.

## Show the next events on the home page

`EventUpcoming` shows up to three coming events as cards, with a link to all. With no event coming up, it shows nothing. Put it into `app/pages/index.vue`, for example after the last section:

```vue [app/pages/index.vue]
    </BlockSection>
    <EventUpcoming />
  </div>
</template>
```

`<EventUpcoming :limit="2" title="Readings" />` changes the number and the heading.

## Change it

- **Texts.** The fixed texts are in `i18n/events/<language>.json`. To change one, set the same key under `events` in your `i18n/<language>.json`.
- **Owners.** When the brick moves to the platform, an owner adds events and marks one as fully booked in the Studio. [Move a brick to the platform]($docs.move-a-brick-to-the-platform) has the steps.
