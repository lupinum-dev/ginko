Diese Anleitung holt die festen Texte einer Seite aus den Templates in eine Datei pro Sprache. Feste Texte sind die Wörter des Layouts: Navigation, Button-Beschriftungen, „Weiterlesen“. Die Inhalte der Bausteine gehören nicht dazu.

Am Ende zeigt eine Seite ihre festen Texte in der Sprache der Leser, und eine Prüfung nennt jeden Text, der noch keine Übersetzung hat.

## Schritte

::steps
#### Eine Datei pro Sprache anlegen

Die Dateien liegen in `i18n/`, neben `nuxt.config.ts`. Der Name ist das Sprachkürzel:

```json [i18n/en.json]
{
  "nav": { "about": "About us" },
  "weekOf": "Week of {date}",
  "dishes": "{count, plural, one {# dish} other {# dishes}}"
}
```

```json [i18n/de.json]
{
  "nav": { "about": "Über uns" },
  "weekOf": "Woche ab {date}",
  "dishes": "{count, plural, one {# Gericht} other {# Gerichte}}"
}
```

Verschachtelung gruppiert Schlüssel. Ein Schlüssel selbst hat keinen Punkt.

#### Einen Text mit t zeigen

```vue
<script setup lang="ts">
const { t } = useI18n()
</script>

<template>
  <h1>{{ t('nav.about') }}</h1>
  <p>{{ t('weekOf', { date: '5. Oktober' }) }}</p>
  <p>{{ t('dishes', { count: 3 }) }}</p>
</template>
```

- `t('nav.about')` liest `about` in `nav`.
- Ein Name in geschweiften Klammern ist ein Parameter. `t('weekOf', { date: '5. Oktober' })` ergibt „Woche ab 5. Oktober“.
- `plural` wählt eine Form nach einer Zahl. `t('dishes', { count: 1 })` ergibt „1 Gericht“, mit `count: 3` ergibt es „3 Gerichte“.

Dein Editor kennt die Schlüssel. Ein Schlüssel, der in keiner Datei steht, ist ein Fehler im Editor.

#### Das Ergebnis prüfen

Öffne die Seite in jeder Sprache. Lass dann die Prüfung laufen:

```bash
npx ginko-i18n check
```

Sie nennt jeden Schlüssel, den eine Sprache nicht hat:

```text
error missing de consent i18n/en.json:5: Missing translation
1 errors, 0 warnings
```

Der Dev-Server liest die Dateien neu, wenn du sie speicherst.
::

## Ein fehlender Text

Ein Schlüssel, der in einer Sprache fehlt, zeigt den Text der Hauptsprache. Der Dev-Server warnt beim Start davor.

## Ein Text mit einem Link

Schreib ein Tag in den Text und fülle es mit `<I18nT>`:

```json [i18n/en.json]
{
  "consent": "I accept the <link>privacy policy</link>."
}
```

```vue
<script setup lang="ts">
const { localePath } = useI18n()
</script>

<template>
  <I18nT k="consent">
    <template #link="{ text }">
      <NuxtLink :to="localePath('/privacy')">{{ text }}</NuxtLink>
    </template>
  </I18nT>
</template>
```

Der Slot hat den Namen des Tags und bekommt die Wörter zwischen den Tags. Übersetzer können den Link im Satz verschieben, und im Text steht kein HTML.
