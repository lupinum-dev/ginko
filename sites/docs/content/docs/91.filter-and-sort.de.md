Diese Anleitung zeigt einen Teil einer Sammlung: nur die Einträge, die passen, in der Reihenfolge, die du willst. Am Ende listet eine Seite die veganen Einträge, die höchstens 4 Euro kosten, den teuersten zuerst.

## Bevor du beginnst

Eine Seite listet eine Sammlung mit `useGinko`. [Inhalte in einer Seite lesen]($docs.read-content-in-a-page) zeigt, wie. Die Beispiele nutzen eine Sammlung `prices` mit `title`, `price` (Geld) und `vegan` (ja/nein).

## Schritte

::steps
#### useGinko durch useGinkoQuery ersetzen

`useGinkoQuery` nimmt den Namen des Bausteins und eine Abfrage:

```vue
<script setup lang="ts">
const cheapVegan = useGinkoQuery('prices', {
  where: { vegan: true, price: { lte: { amount: 400 } } },
  order: 'price desc, title',
  limit: 10,
})
</script>

<template>
  <ul>
    <li v-for="item in cheapVegan.items" :key="item.id">{{ item.data.title }}</li>
  </ul>
  <p>{{ cheapVegan.total }} Einträge</p>
</template>
```

- `where` nennt pro Feld einen Wert oder eine Bedingung. Jedes Feld muss passen.
- `order` nennt die Felder, nach denen sortiert wird. `desc` sortiert abwärts, `asc` ist der Standard.
- `limit` ist die größte Zahl von Einträgen.

Das Ergebnis hat `items` und `total`, die Zahl aller Treffer.

#### Das Ergebnis prüfen

Mit den Einträgen Coffee (3,50, vegan), Tea (2,80, vegan), Cake (4,20, nicht vegan) und Soup (6,50, vegan) zeigt die Seite „Coffee, Tea“ und „2 Einträge“.
::

## Bedingungen

Ein Feld in `where` nimmt einen Wert, dem das Feld gleichen muss, oder eine dieser Bedingungen:

| Bedingung | Passt, wenn das Feld |
| --- | --- |
| `eq`, `ne` | gleich ist oder nicht gleich ist. Bei einem Listenwert zählt ein Element. |
| `gt`, `gte`, `lt`, `lte` | größer oder kleiner ist. Geld vergleicht nach `amount`, ein Datumsbereich nach seinem ersten Tag. |
| `in` | einem der Werte einer Liste gleicht |
| `contains` | ein Text ist, der den Text enthält, oder eine Liste, die den Wert enthält. Groß- und Kleinschreibung zählen gleich. |

Ein Betrag steht in der kleinsten Einheit: `{ lte: { amount: 400 } }` heißt höchstens 4,00.

## Eine Seite nach der anderen zeigen

`limit` mit `page` liefert eine Seite der Treffer. `page` beginnt bei 1:

```ts
const paged = useGinkoQuery('prices', { limit: 2, page: 2 })
```

Das Ergebnis hat auch `page` und `pages`. Bei vier Einträgen enthält `paged.items` die Einträge 3 und 4, und `paged.pages` ist 2.

## Die Werte eines Feldes zählen

`facets` zählt die Werte von Feldern über alle Treffer, zum Beispiel für Filter-Buttons mit einer Zahl:

```ts
const counted = useGinkoQuery('prices', { facets: ['vegan'] })
// counted.value.facets ist { vegan: { true: 3, false: 1 } }
```

## Zum vorigen und nächsten Eintrag verlinken

`useGinkoNeighbors` liefert die Einträge vor und nach einem Eintrag, zum Beispiel unter einem Artikel:

```ts
const neighbors = useGinkoNeighbors('prices', () => item.id)
// neighbors.value.prev und neighbors.value.next sind Einträge oder undefined
```

Es nutzt die Reihenfolge des Bausteins. Gib `{ order: 'date desc' }` als drittes Argument für eine andere Reihenfolge an.

## Was die Abfrage liest

`useGinkoQuery` arbeitet auf den Inhalten, die die Seite schon hat. Es fragt keine Datenbank und keinen Server. Ein Feld, das der Baustein nicht hat, ist ein Fehler in deinem Editor.
