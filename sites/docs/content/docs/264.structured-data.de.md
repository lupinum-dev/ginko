Suchmaschinen zeigen reichere Ergebnisse für Seiten, die sich selbst als Daten beschreiben: ein Betrieb mit seiner Adresse, eine Frage mit ihrer Antwort, eine Veranstaltung mit ihrem Datum. Das Format ist JSON-LD mit dem Vokabular von schema.org. Diese Anleitung ergänzt es auf deinen Seiten.

## Was die Seite von selbst schreibt

Die Startseite hat einen Eintrag `WebSite` mit Name, Adresse und Sprache der Seite. Mit `seo.organization` in der Konfiguration hat sie auch einen Eintrag `Organization`:

```ts [ginko.config.ts]
seo: {
  organization: {
    logo: '/logo.png',
    sameAs: ['https://www.instagram.com/linde'],
  },
},
```

`sameAs` nennt die Profile des Betriebs an anderen Orten.

## Schritte

::steps
#### Den Helfer eines fertigen Bausteins nutzen

Die Bausteine aus `@lupinum/ginko/basics` haben Helfer, die die Daten aus ihren Einträgen bauen. Für Fragen und Antworten:

```vue [app/pages/questions.vue]
<script setup lang="ts">
import { faqJsonLd } from '@lupinum/ginko/basics'

const faq = useGinko('faq')
useGinkoSeo(() => ({
  title: 'Fragen',
  jsonLd: [faqJsonLd(faq.value.items.map((item) => item.data))],
}))
</script>
```

| Baustein | Helfer | Typ bei schema.org |
| --- | --- | --- |
| `site()` | `siteJsonLd` | Organization, LocalBusiness oder NGO |
| `people()` | `personJsonLd` | Person |
| `posts()` | `postJsonLd` | BlogPosting |
| `jobs()` | `jobJsonLd` | JobPosting |
| `faq()` | `faqJsonLd` | FAQPage |

#### Eigene Daten schreiben

Für alles andere gibst du `jsonLd` ein Objekt:

```ts
useGinkoSeo(() => ({
  title: post.value.data.title,
  type: 'article',
  jsonLd: [{
    '@context': 'https://schema.org',
    '@type': 'NewsArticle',
    headline: post.value.data.title,
    datePublished: post.value.data.date,
  }],
}))
```

#### Das Ergebnis prüfen

Öffne den Quelltext der Seite und such nach `application/ld+json`. Der Block enthält dein Objekt. Gib dann die Adresse der Live-Seite in den Rich Results Test von Google ein. Er zeigt, welche Ergebnisse die Seite bekommen kann.
::

## Eine Brotkrumen-Spur

`breadcrumbJsonLd` baut die Spur von der Startseite bis zur aktuellen Seite:

```ts
import { breadcrumbJsonLd } from '@lupinum/ginko'

const { url } = useGinkoSite()
const crumbs = useGinkoBreadcrumbs(['pages'])
useGinkoSeo(() => ({
  title: page.value.data.title,
  jsonLd: [breadcrumbJsonLd(crumbs.value, url)],
}))
```
