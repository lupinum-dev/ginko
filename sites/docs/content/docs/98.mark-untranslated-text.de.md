Ein Text ohne Übersetzung erscheint in der Hauptsprache. Auf einer deutschen Seite ist der Name eines Gerichts dann vielleicht englisch. Diese Anleitung kennzeichnet so einen Text, damit ein Screenreader ihn in der richtigen Sprache ausspricht.

## Bevor du beginnst

Eine Seite listet eine Sammlung, und manche Einträge haben keine Übersetzung. [Inhalte in einer Seite lesen]($docs.read-content-in-a-page) zeigt die Liste.

## Schritte

::steps
#### Fragen, welche Sprache ein Wert hat

`useGinkoLang` gibt eine Funktion zurück. Sie nimmt einen Eintrag und den Namen eines Feldes. Sie liefert das Sprach-Tag der Hauptsprache, wenn der Wert ein Fallback ist, und `undefined`, wenn der Wert übersetzt ist:

```vue
<script setup lang="ts">
const prices = useGinko('prices')
const langOf = useGinkoLang()
</script>

<template>
  <ul>
    <li v-for="item in prices.items" :key="item.id" :lang="langOf(item, 'title')">
      {{ item.data.title }}
    </li>
  </ul>
</template>
```

Vue lässt ein Attribut weg, dessen Wert `undefined` ist. Ein übersetzter Text bekommt kein `lang`-Attribut und übernimmt die Sprache der Seite.

#### Das Ergebnis prüfen

Öffne die deutsche Seite und sieh dir die Liste im Inspektor des Browsers an. Mit „Tea“ übersetzt zu „Tee“ und den anderen Einträgen ohne Übersetzung:

```html
<li lang="en">Coffee</li>
<li>Tee</li>
<li lang="en">Cake</li>
```
::

## Werte in einem Einzelstück oder einem Listenfeld

Bei einem Einzelstück gibst du das Einzelstück selbst an: `langOf(start, 'title')`.

Bei einer Zeile eines Listenfeldes nennst du die Zeile über ihre `_id`:

```vue
<span :lang="langOf(lunch, `days.${day._id}.dish`)">{{ day.dish }}</span>
```

Bei der Beschreibung eines Bildfeldes `photo` ist der Name `photo.alt`.

## Was über den Fallback entscheidet

Ein Baustein ohne Route zeigt unübersetzte Einträge in der Hauptsprache. Ein Baustein mit Route lässt sie in der Sprache weg. [Einträgen eigene Seiten geben]($docs.entry-pages#was-eine-route-mitbringt) erklärt die Einstellung `untranslated`.
