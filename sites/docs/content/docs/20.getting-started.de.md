In fünf Minuten hast du eine Seite, die auf deinem Rechner läuft und ihren Text aus einer Markdown-Datei liest. Sie braucht kein Konto und keine Plattform.

Du brauchst Node.js 22.18 oder neuer (22, 24 oder 26) und npm, pnpm oder bun.

## Die Seite anlegen und starten

::steps
#### Die Seite anlegen

```bash
npm create ginko@latest meine-seite -- --locales de
```

Der Befehl legt den Ordner `meine-seite` mit einer kleinen deutschen Seite an: eine Seite und ein Text. Ohne `--locales de` ist sie englisch. Schreib die Optionen nach `--`, sonst behält npm sie für sich.

#### Installieren und starten

```bash
cd meine-seite
npm install
npm run dev
```

npm warnt vielleicht, dass esbuild ein Install-Skript hat. Die Seite läuft auch ohne.

Öffne `http://localhost:3000`. Die Seite zeigt „Hallo Ginko“.

#### Den Text ändern

Öffne `content/start.md`. Die Zeilen zwischen den beiden `---` sind die Felder, der Text darunter ist das Markdown-Feld:

```markdown [content/start.md]
---
title: Hallo Ginko
---

Dieser Text liegt in `content/start.md`. Ändere ihn, und die Seite zeigt den neuen Text.
```

Ändere den Titel und speichere die Datei. Die Seite im Browser zeigt den neuen Titel.
::

## Was im Ordner liegt

| Datei | Was sie tut |
| --- | --- |
| `ginko.config.ts` | Beschreibt die Inhalte der Seite: ein Baustein `start` mit einem Titel und einem Text. |
| `content/start.md` | Der Inhalt dieses Bausteins. |
| `app/pages/index.vue` | Die Seite. Sie liest den Baustein mit `useGinko('start')`. |
| `nuxt.config.ts` | Schaltet das Ginko-Modul ein. |

Ein Baustein ist eine Art von Inhalt. [Was Ginko ist]($docs.what-ginko-is) erklärt die Begriffe, und [Eine Seite von Hand bauen]($docs.build-a-site-by-hand) schreibt diese Dateien eine nach der anderen.

## Mit einem Template beginnen

Die kleine Seite reicht für einen ersten Blick. Für eine echte Seite beginnst du mit einem Template. Ein Template ist eine vollständige Seite mit Seiten, Beispielinhalten, einem Design und zwei oder mehr Sprachen:

```bash
npm create ginko@latest mein-gasthaus -- --template restaurant
```

`--locales` wählt die Sprachen und ihre Reihenfolge. Die erste ist die Hauptsprache:

```bash
npm create ginko@latest mein-gasthaus -- --template restaurant --locales de,en
```

[Templates]($docs.templates) zeigt alle zehn Templates mit einer Live-Demo.
