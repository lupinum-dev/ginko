This recipe adds a pricing page to a site that runs and was made from a template, for example the `starter` of the [Quick start]($docs.getting-started). At the end, `/pricing` shows your plans side by side (stacked on a phone), each with its price per month and per year or "On request", what it includes and a button.

The template `saas` has the finished feature. You copy its files into your site. Unlike blog, events and FAQ, the brick itself comes with the copy: it lives in `app/bricks/pricing.ts`, not in `@lupinum/ginko/basics`.

## What you add

| Part | Where |
| --- | --- |
| Brick | `pricing` from `app/bricks/pricing.ts`, in `ginko.config.ts` |
| Content | `content/pricing/<n>.<name>.md` |
| Page | `app/pages/pricing.vue` |
| Code | `app/components/pricing/Plans.vue`, `app/composables/usePricing.ts` |
| Texts | `i18n/pricing/<language>.json` |

## Steps

::steps
#### Get the files

In your site's folder, create a copy of the template `saas` next to it, in the languages of your site. It needs no `npm install`. If you made it for [Add an FAQ]($docs.add-an-faq) and kept it, use that one:

```bash
npm create ginko@latest ../saas-files -- --template saas --locales en,de
```

#### Copy the pricing into your site

```bash
mkdir -p app/components/pricing
cp ../saas-files/app/bricks/pricing.ts app/bricks/
cp ../saas-files/app/components/pricing/Plans.vue app/components/pricing/
cp ../saas-files/app/composables/usePricing.ts app/composables/
cp ../saas-files/app/pages/pricing.vue app/pages/
cp -R ../saas-files/i18n/pricing i18n/
```

Copy only `Plans.vue`. `More.vue` in the same folder holds the billing questions of the saas template.

#### Add the brick and the page

```ts [ginko.config.ts]
import { pages } from './app/bricks/pages.ts'
import { pricing } from './app/bricks/pricing.ts'

export default defineSite({
  // …
  pages: {
    home: localized('/'),
    pricing: localized('/pricing'),
  },
  bricks: {
    // … the bricks you have
    pricing: pricing({ source: 'files' }),
  },
})
```

The page key must stay `pricing`, because the page is `app/pages/pricing.vue`. Prices are in `currency` of `ginko.config.ts`.

#### Write the plans

One file per plan. The number sets the order:

```markdown [content/pricing/1.small.md]
---
name: Small
summary: For a museum with one exhibition a year.
pricing: price
monthly: 290
yearly: 2900
included:
  - item: Up to 5,000 words a month
  - item: Delivery within five working days
actionLabel: Ask for this plan
---
```

```markdown [content/pricing/2.large.md]
---
name: Large
summary: For institutes that publish every month.
pricing: onRequest
included:
  - item: Any number of words
  - item: A second reader for every text
actionLabel: Ask for a quote
---
```

`pricing` is a choice you always write: `price` needs both `monthly` and `yearly`, `onRequest` shows no price. The amounts are in the currency of the site, so `290` is €290. `recommended: true` marks a plan with the word "Recommended". `actionUrl` sends the button to an address, for example the sign-up page of your app. Without it, the button leads to the page `pages/contact`, or, without that page, to an email to the address in `content/site.md`.

#### Put the pricing into the menu

```ts [app/app.config.ts]
nav: [{ entry: 'pages/about' }, { page: 'pricing', label: { en: 'Pricing', de: 'Preise' } }, { entry: 'pages/contact' }],
```
::

## Check that it works

- Open `http://localhost:3000/pricing`. It shows "Small" with "€290 per month" and "or €2,900 per year", and "Large" with "On request".
- Click "Ask for this plan". It opens the contact page.
- Make the browser narrow. The plans stand one below the other.
- Remove `yearly` from `1.small.md` and run `npm run check`. It reports the missing amount. Put it back.

Then delete the folder `../saas-files`.

## Prices with or without VAT

Add `vat` to `site` in `app/app.config.ts`, and a line above the plans says so:

```ts [app/app.config.ts]
vat: 'excluded',   // prices to businesses: "All prices plus VAT."
```

Use `'included'` for prices to consumers. Without `vat`, the page says nothing about VAT.

## Change it

The title and the lead of the page are in `i18n/pricing/<language>.json`. To change them, set `pricing.title` and `pricing.lead` in your `i18n/<language>.json`.
