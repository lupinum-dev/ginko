`@lupinum/ginko-components` gibt Markdown-Text seine Bausteine: Hinweise, Reiter, Karten, Code-Gruppen, Video, Quiz und mehr. Jede Gruppe hat eine Seite, die jede Komponente live zeigt, mit dem Markdown, aus dem sie entsteht, und ihren Props.

Um sie zu nutzen, folge zuerst [Komponenten einrichten]($docs.set-up-components).

## Einen Tag schreiben

Eine Block-Komponente beginnt mit zwei Doppelpunkten und ihrem Namen und endet mit zwei Doppelpunkten. Der Text dazwischen ist ihr Inhalt:

```md
::callout{title="Vorsicht"}
Das gilt nur für neue Seiten.
::
```

Eine Komponente, die andere Komponenten enthält, bekommt einen Doppelpunkt mehr als die darin:

```md
:::tabs
::tab{title="Monatlich"}
12 € im Monat.
::
::tab{title="Jährlich"}
120 € im Jahr.
::
:::
```

Eine Inline-Komponente hat einen Doppelpunkt und steht in einem Satz. Ihr Text steht in eckigen Klammern:

```md
Drück :kbd[Strg] + :kbd[S] zum Speichern. Die Funktion ist :badge[neu]{color="success"}.
```

Manche Komponenten haben einen benannten Slot. Er beginnt mit `#` und seinem Namen auf einer eigenen Zeile, siehe [`quiz-question`]($docs.components-learning).

## Props schreiben

Props stehen in geschweiften Klammern nach dem Namen: `::card{title="Garten" iconColor="primary"}`.

- Schreib jeden Namen genau wie in den Listen. Ein Name aus zwei Wörtern ist camelCase (`iconColor`, `defaultValue`). `icon-color` ist eine unbekannte Prop.
- Eine Ja/Nein-Prop wirkt allein (`open`) oder mit `"true"` und `"false"`.
- Eine Prop, die als *Pflicht* markiert ist, muss da sein. `ginko check` nennt eine fehlende.

## Props, die viele Tags teilen

| Prop | Werte | Bedeutung |
| --- | --- | --- |
| `icon` | Ein Iconify-Name wie `lucide:book-open`. Ein Name ohne Präfix meint Lucide. | Zeigt ein Icon. Es braucht `@nuxt/icon` und den Icon-Satz, siehe [Icons hinzufügen]($docs.set-up-components#icons-hinzufuegen). Hinweise kennen außerdem sechs eingebaute Namen. |
| `appearance` | `quiet` oder `tint` | Ein Rahmen oder eine gefüllte Fläche, siehe [Rahmen oder Fläche]($docs.theme-the-components#rahmen-oder-flaeche). |
| `title` | Text | Die Überschrift der Komponente. |

Die Tags mit `appearance` sind `callout` und seine Kurzformen, `aside`, `excerpt`, `accordion`, `collapse`, `tabs`, `cards`, `card`, `read-more`, `inline-toc`, `steps`, `files`, `api` und `quiz`.

## Wo ein Tag stehen darf

- Ein Markdown-Feld nimmt Komponenten nur mit dem Profil `page` an, siehe [Feldtypen]($docs.field-types#text-fmarkdown).
- Manche Tags gehören zusammen: `tab` steht nur in `tabs`, `column` nur in `layout`, `timeline-item` nur in `timeline`, `accordion-item` nur in `accordion`, `quiz-question` nur in `quiz`, `api-param` nur in `api`.
- Ginko zeichnet die HTML-Elemente `embed` und `iframe` nie aus Markdown. `::embed` ist immer die Komponente.

## Feste Texte

Die Komponenten haben feste Texte, zum Beispiel die Beschriftung des Kopierknopfs. Sie folgen der Sprache der Seite. Eine Seite ändert einen davon in ihrer eigenen Sprachdatei unter `components`:

```json [i18n/de.json]
{ "components": { "code": { "copy": "Kopieren" } } }
```

| Schlüssel | Deutscher Text |
| --- | --- |
| `code.copy`, `code.copied`, `code.copyFailed` | Code kopieren, Kopiert, Kopieren nicht möglich |
| `code.terminal`, `code.untitled` | Terminal, Code {number} |
| `media.zoom`, `media.close`, `media.play` | Bild vergrößern, Schließen, Abspielen |
| `media.consent` | Beim Abspielen lädt {provider} Inhalte und setzt ggf. Cookies. |
| `embed.load`, `embed.consent` | Inhalt laden; Beim Laden lädt {provider} Inhalte und setzt ggf. Cookies. |
| `quiz.progress`, `quiz.question` | Frage {current} von {total}, Frage {number} |
| `quiz.back`, `quiz.next`, `quiz.check`, `quiz.results`, `quiz.retry` | Zurück, Weiter, Antwort prüfen, Ergebnis anzeigen, Erneut versuchen |
| `quiz.correct`, `quiz.incorrect`, `quiz.multiple` | Richtig, Nicht richtig, (mehrere Antworten möglich) |
| `quiz.score`, `quiz.perfect`, `quiz.retryPrompt` | {correct} von {total} richtig; Alles richtig.; Weiterlernen und erneut versuchen. |
| `api.defaultGroup`, `api.required`, `api.deprecated`, `api.since` | Parameter, erforderlich, veraltet, seit {version} |
| `collapse.more`, `collapse.lines` | Mehr anzeigen, Alle {count} Zeilen anzeigen |
| `toc.title` | Auf dieser Seite |

`components` ist ein reservierter Name. Nutze ihn nicht für deine eigenen Texte.
