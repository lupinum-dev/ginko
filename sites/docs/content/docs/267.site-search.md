This guide adds a search box to a site. At the end, a visitor types a word and gets links to the entries and sections that contain it. The search runs in the browser and needs no service.

## What Ginko provides

Ginko builds one search index per language and serves it at `/__ginko/search/<language>.json`. It holds one record for the start of each entry and one for each section under a `##` or `###` heading. Only entries with their own address are in it.

You write the box and the list of results.

## Steps

::steps
#### Add the search component

```vue [app/components/SiteSearch.vue]
<script setup lang="ts">
import type { SearchHit, SearchIndex, SearchIndexJson } from '@lupinum/ginko/search'

const { locale } = useI18n()
const query = ref('')
const hits = ref<SearchHit[]>([])
const indexes = new Map<string, SearchIndex>()

watch(query, async (text) => {
  // Load the search engine and the index only when someone searches.
  const { loadIndex, search } = await import('@lupinum/ginko/search')
  let index = indexes.get(locale.value)
  if (!index) {
    index = await loadIndex(await $fetch<SearchIndexJson>(`/__ginko/search/${locale.value}.json`))
    indexes.set(locale.value, index)
  }
  hits.value = search(index, text, { limit: 8 })
})
</script>

<template>
  <input v-model="query" type="search" aria-label="Search">
  <ul>
    <li v-for="hit in hits" :key="hit.id">
      <NuxtLink :to="hit.url">{{ hit.heading ?? hit.title }}</NuxtLink>
      <p>{{ hit.excerpt }}</p>
    </li>
  </ul>
</template>
```

The component loads the search code and the index only when a visitor types. Pages without a search stay small.

#### Put it on a page

```vue [app/pages/search.vue]
<template>
  <main>
    <SiteSearch />
  </main>
</template>
```

#### Check the result

Open `/search` and type a word from one of your entries. With an entry "We are open" that has a section "Opening hours" with the sentence "We open the garden at noon":

- "garden" finds the section. Its link is `/news/opening#opening-hours`, and the excerpt is the sentence.
- "opend", with a typo, finds "Opening hours" and "We are open".
::

## What a hit holds

| Value | Meaning |
| --- | --- |
| `url` | The address of the entry, with the anchor of its section |
| `title` | The title of the entry |
| `heading` | The heading of the section, when the hit is a section |
| `excerpt` | The text around the word |
| `score` | How well the hit matches |

## How the search matches

- It finds a word by its beginning and accepts small typos.
- In German, English, French, Italian, Spanish, Dutch and Portuguese it finds other forms of a word: "connecting" finds "connected".
- Accents do not matter: "cafe" finds "café".
- Each language has its own index. A visitor on a German page searches the German texts.
