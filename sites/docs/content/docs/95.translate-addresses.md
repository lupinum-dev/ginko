This guide gives one page a path of its own in each language: `/about` in English and `/de/ueber-uns` in German. At the end, both addresses show the same page, links follow the language of the reader, and the sitemap names both.

The guide is for fixed pages such as About or Contact. For the pages of entries, read [Give entries their own pages]($docs.entry-pages).

## Before you start

The site has two languages. [Add a language]($docs.add-a-language) shows how to add one.

## Steps

::steps
#### Create the page with the path of the main language

The file name is the path in the main language:

```vue [app/pages/about.vue]
<script setup lang="ts">
definePageMeta({ i18n: { paths: { de: '/ueber-uns' } } })
</script>

<template>
  <main>
    <h1>About us</h1>
  </main>
</template>
```

`definePageMeta` names the path in each other language, without the language prefix. Ginko adds `/de` itself. Without this line, the German address is `/de/about`.

#### List the page in the config

Add the page to `pages` in `ginko.config.ts`, with the prefix:

```ts [ginko.config.ts]
pages: {
  home: { en: '/', de: '/de' },
  about: { en: '/about', de: '/de/ueber-uns' },
},
```

Ginko uses `pages` for the sitemap, and the key `about` gives the page a name for links.

#### Link to the page

Never write the path of one language into a link. Ask for the path instead:

```vue
<script setup lang="ts">
const path = useGinkoPath()
</script>

<template>
  <NuxtLink :to="path('about')">About us</NuxtLink>
</template>
```

`path('about')` returns `/about` on an English page and `/de/ueber-uns` on a German page. `path('about', 'de')` returns the German path on every page.

#### Check the result

1. `/about` and `/de/ueber-uns` show the page.
2. `/de/about` answers 404. A page has exactly one address per language.
3. `/sitemap.xml` names both addresses.
::

## A page that is not in the config

`localePath` from `useI18n` translates a path of the main language without a key:

```ts
const { localePath } = useI18n()
localePath('/about')        // '/about', or '/de/ueber-uns' on a German page
localePath('/about', 'de')  // '/de/ueber-uns'
```

Use it for pages of your own site only. For an entry, use `item.url`.
