This guide runs the platform on your computer. At the end, the Studio runs on `http://localhost:3100`, you are signed in as admin, you have edited the demo site, and the platform has a site of your own. You need no account for this: the backend runs locally.

## Before you start

You have Node 22.18 or later, 24 or 26, and npm. Port 3100 is free: the Studio needs it.

## Steps

::steps
#### Create the project

```bash
npm create ginko@latest my-cms -- --platform
```

The folder `my-cms` runs the platform: the Studio and its backend. The code comes from three packages, `@lupinum/ginko`, `@lupinum/ginko-server` and `@lupinum/ginko-studio`, so the folder holds only their settings and a `README.md`.

#### Install

```bash
cd my-cms
```

```bash
npm install
```

With pnpm, keep the file `pnpm-workspace.yaml`: Convex needs the real folders that its setting `nodeLinker: hoisted` installs. yarn and bun are not tested.

#### Start the platform

```bash
npm run dev
```

The first start downloads the local backend, which can take a minute. When the Studio is ready, the terminal shows:

```text
The Studio runs on http://localhost:3100
Sign in as admin@example.test. The sign-in code appears here in the terminal; no mail is sent.
Press Ctrl-C to stop the Studio and the local backend.
```

If port 3100 is in use, the command stops before it starts anything and says so.

#### Sign in

Open `http://localhost:3100`, enter `admin@example.test` and choose "Send code". The code appears in the terminal:

```text
Sign-in code for admin@example.test: 123456
```

Enter it in the Studio. This address is the admin of the local platform.

#### Look at the demo site

The first start loads a site called "Demo", so there is content to edit at once. Open it and change a text.

When you do not need it any more, delete it: open the site, then Team › Delete site. To start a new project without it, run `npm run dev -- --no-demo` the first time.

#### Create your first site

Choose "New site" and fill in three fields:

- **Name**: what the site is called in the Studio and in mails.
- **Website address**: where the website is online, or will be.
- **Identifier**: the same value as `site` in the `ginko.config.ts` of the website. It cannot be changed later.

Choose "Create site". The Content page of the new site shows "Connect the website" with three steps. [Connect a website]($docs.connect-a-website) explains them.
::

## See all output

`npm run dev` shows only short progress lines until the Studio is ready. To see all output of the backend and the Studio from the start, run:

```bash
npm run dev -- --verbose
```

If something fails before the Studio is ready, the command shows the last lines of the process that failed.

## Stop the platform

Press Ctrl-C in the terminal. It stops the Studio and the local backend together. The local backend keeps its data in the project folder, so the next `npm run dev` starts with your sites and content.
