title: Field types
description: Every field type of a brick. The options of each type, their defaults and limits, and the value the site reads.

A field is one value in a brick. You build it with `f.<type>(label, options)` from `@lupinum/ginko`:

```ts
import { f } from '@lupinum/ginko'

const fields = {
  name: f.text('Name', { max: 120 }),
  price: f.money('Price', { optional: true }),
}
```

The label is the name of the field in the editor. It is one text, or one text per language: `{ en: 'Name', de: 'Name' }`. A label per language must contain the main language or English.

To learn how fields fit into a brick, read [Bricks]($docs.bricks).

## All types

| Builder | Holds | Value the site reads | Translatable |
| --- | --- | --- | --- |
| [`f.text`](#text-ftext) | a short text | `string` | yes, no with `format` |
| [`f.longtext`](#text-flongtext) | a text of several sentences | `string` | yes |
| [`f.markdown`](#text-fmarkdown) | formatted text | Markdown tree | yes |
| [`f.slug`](#text-fslug) | the address of an entry | `string` | always |
| [`f.number`](#numbers-fnumber) | a number | `number` | no |
| [`f.money`](#numbers-fmoney) | an amount | `{ amount, currency }` | no |
| [`f.boolean`](#numbers-fboolean) | yes or no | `boolean` | no |
| [`f.date`](#dates-and-times-fdate) | a day | `'2026-10-12'` | no |
| [`f.time`](#dates-and-times-ftime) | a time of day | `'18:30'` | no |
| [`f.daterange`](#dates-and-times-fdaterange) | a first and a last day | `{ from, to }` | no |
| [`f.choice`](#choices-fchoice) | one of several options | the value of the option | no |
| [`f.choices`](#choices-fchoices) | several options | list of values | no |
| [`f.list`](#lists-flist) | rows with columns | list of rows, each with `_id` | per column |
| [`f.rows`](#lists-frows) | a fixed set of rows with columns | one object per row, by row key | per column |
| [`f.image`](#images-and-files-fimage) | a photo | `{ url, alt, width, height }` | only `alt` |
| [`f.file`](#images-and-files-ffile) | a PDF | `{ url, name, size }` | no |
| [`f.ref`](#references-fref) | one entry of a collection | the id of the entry | no |
| [`f.refs`](#references-frefs) | several entries of a collection | list of ids | no |

"Translatable" means that the field has one value per language. All other fields have one value for the whole site.

## Options for every type

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `optional` | `true` | required | The field may stay empty. |
| `hint` | text, or one text per language | none | A help text under the field in the editor. |
| `default` | the value of the field | none | The value a new entry starts with. `f.markdown`, `f.image` and `f.file` have no `default`. |
| `translate` | `false` or `'manual'` | translated | `false` gives a translatable type one value for all languages. `'manual'` keeps the field translated and turns off translation suggestions. |
| `showWhen` | `{ field, is }` or `{ field, not }` | always shown | The editor shows the field only while another field next to it has that value. A missing value counts as "not". The stored value and the checks stay the same. |
| `group` | text, or one text per language | none | The editor shows the field under this heading. Not for the columns of a list or a rows field. |

A required field with `showWhen` is required only while the editor shows it. Its type in the site is therefore optional.

Write a `default` the way the site reads the value. Two types differ: a translatable text takes one text (the main language) or one text per language, and `f.money` takes `{ amount: 1250 }` without the currency.

An option that a type does not have is a type error in `ginko.config.ts`.

## Text

### `f.text`

A short text on one line.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `max` | number | `200` | Most characters. At most `500`, or `2000` with `format: 'url'`. |
| `format` | `'url'`, `'email'` or `'tel'` | none | The text must be an address of that kind. A text with `format` is not translatable. |

```ts
phone: f.text('Phone', { format: 'tel' }),
```

### `f.longtext`

A plain text of several sentences, without formatting.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `max` | number | `2000` | Most characters. At most `5000`. |

### `f.markdown`

Formatted text. The site reads a Markdown tree and shows it with `<GinkoMarkdown>`.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `profile` | `'inline'`, `'basic'`, `'rich'` or `'page'` | `'rich'` | What the text may contain, see the table below. |
| `max` | number | `50000` | Most characters. At most `500000`. |

Each profile allows what the profile before it allows, and more:

| Profile | Allows |
| --- | --- |
| `inline` | One paragraph with bold, italic, strikethrough, code and links. |
| `basic` | Also headings h2 to h4, lists, task lists, quotes, dividers and footnotes. |
| `rich` | Also tables, images, code blocks, math and mermaid diagrams. |
| `page` | Also h1, h5, h6 and components such as `::callout`. |

In a brick with `source: 'files'`, the Markdown field is the text of the file below the frontmatter. Such a brick has at most one Markdown field, and its lists have no Markdown column.

### `f.slug`

The address of an entry, such as `opening` in `/news/opening`. Ginko makes it once from another text field. Each language has its own slug.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `from` | name of a `text` or `longtext` field | required | The field the slug is made from. |

A slug is a field of the brick itself: a list has no slug column. A collection with a `route` needs a slug field with the name `slug`. See [Routes and slugs]($docs.bricks#routes-and-slugs).

## Numbers

### `f.number`

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `min` | number | required | Smallest value. |
| `max` | number | required | Largest value. |
| `step` | number | required | The distance between two values, more than `0`. Use `1` for whole numbers. |
| `unit` | text | none | A unit shown next to the field, such as `kg`. |

```ts
seats: f.number('Seats', { min: 1, max: 200, step: 1 }),
```

### `f.money`

An amount in minor units of its currency. 12.50 EUR is `{ amount: 1250, currency: 'EUR' }`. A currency without minor units, such as JPY, uses whole units.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `min` | number | `0` | Smallest amount in minor units. Not negative. |
| `max` | number | `100000000` | Largest amount in minor units. At most `100000000`. |
| `currency` | ISO 4217 code | the `currency` of the site | The currency of this field, such as `'CHF'`. |

Show the value with [`formatMoney`]($docs.reading-content#formatmoney).

### `f.boolean`

`true` or `false`. No options of its own.

## Dates and times

### `f.date`

A day as `YYYY-MM-DD`. The day counts in the time zone of the site (`timeZone` in `ginko.config.ts`). No options of its own.

### `f.time`

A time of day as `HH:MM`.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `after` | name of another `time` field of the brick | none | This time must be later than that field. Ginko checks it when both have a value. |

```ts
from: f.time('Opens at'),
to: f.time('Closes at', { after: 'from' }),
```

### `f.daterange`

A first and a last day: `{ from: '2026-10-12', to: '2026-10-14' }`. No options of its own.

## Choices

### `f.choice`

One of several options.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `options` | list of options | required | 1 to 50 options. Each value appears once. |

An option is a text, or `{ value, label }` when the editor shows another name than the stored value. The site reads the value only. Show your own text for each value in the site.

```ts
day: f.choice('Day', { options: [{ value: 'mo', label: 'Monday' }, { value: 'tu', label: 'Tuesday' }], default: 'mo' }),
```

In the site, this field has the type `'mo' | 'tu' | UnknownChoice`. `UnknownChoice` stands for an option that a later release adds. Give it a fallback text.

### `f.choices`

Several of the options, as a list of values.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `options` | list of options | required | As for `f.choice`. |
| `max` | number | all options | Most options an entry may pick. |
| `askAgainWhen` | name of a `text` or `longtext` field next to it | none | When that text changes in the main language and the choice stays, the editor asks whether the choice is still right. |

```ts
allergens: f.choices('Allergens', { options: ['gluten', 'milk', 'nuts'], askAgainWhen: 'dish' }),
```

## Lists

### `f.list`

Rows with the same columns, for example the days of a lunch menu. The site reads a list of rows. Each row has its columns and an `_id` that stays the same when rows move.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `fields` | fields | required | The columns. Each column is a field of any type except `f.list`, `f.rows` and `f.slug`. |
| `itemLabel` | text, or one text per language | required | The name of one row in the editor, such as "Day". |
| `max` | number | required | Most rows, `1` to `50`. |
| `min` | number | `0` | Fewest rows, `0` to `max`. |

```ts
dates: f.list('Dates', {
  itemLabel: 'Date',
  fields: {
    day: f.date('Day'),
    note: f.text('Note', { max: 200, optional: true }),
  },
  max: 20,
}),
```

A column name starts with a lowercase letter and has only letters and digits. `_id` is taken.

A list with a fixed set of rows, such as one row per weekday, is a [`f.rows`](#lists-frows) field.

### `f.rows`

A fixed set of rows with the same columns, for example the opening hours of each day of the week. The editor shows every row with its name; rows are not added, removed or moved. The site reads one object per row, by its key: `{ mo: { … }, tu: { … }, … }`.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `rows` | `'weekdays'`, `'workdays'` or a list of `{ key, label }` | required | The rows. `'weekdays'`: the seven days, `mo` to `su`. `'workdays'`: the workdays of the site's week. A list: 1 to 50 rows of your own. |
| `fields` | fields | required | The columns of every row. Each column is a field of any type except `f.list`, `f.rows` and `f.slug`. |

With `'weekdays'` or `'workdays'` the site states its week (`week: { firstDay: 'monday', workdays: 5 }` in `defineSite`). The editor shows the days in that order, named in the editor's language. A row's `key` follows the rule for column names; its `label` is a text or one text per language.

```ts
days: f.rows('Days', {
  rows: 'workdays',
  fields: {
    dish: f.text('Dish', { max: 200, default: 'To be announced' }),
    price: f.money('Price', { optional: true }),
  },
}),
```

A new entry starts with every row filled from the columns' defaults, or with the field's `default` (one object per row).

## Images and files

### `f.image`

A photo. The site reads `{ url, alt, width, height }`, and `focus: { x, y }` when the owner set a focus point. Show it with `<GinkoImage>`.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `aspect` | a ratio such as `'3:2'`, or named ratios | none | The shape the site shows the photo in. The editor previews the photo in that shape. |

```ts
photo: f.image('Photo', { aspect: { card: '3:2', header: '21:9' } }),
```

With named ratios, `<GinkoImage frame="card">` picks one. `aspect` changes no stored value.

The description `alt` is required in the main language and has at most 300 characters. It is the only part of an image that is translatable.

### `f.file`

A file for download. The site reads `{ url, name, size }`.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `accept` | `['pdf']` | required | The file types the field takes. PDF is the only one. |
| `maxBytes` | number | required | Largest file size in bytes. At most 10 MB. |

```ts
menu: f.file('Menu as PDF', { accept: ['pdf'], maxBytes: 5 * 1024 * 1024 }),
```

## References

### `f.ref`

Points to one entry of a collection. The site reads the id of that entry.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `to` | name of a collection brick | required | The collection the entry comes from. |

### `f.refs`

Points to several entries of a collection. The site reads a list of ids.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `to` | name of a collection brick | required | The collection the entries come from. |
| `max` | whole number above `0` | no limit | Most entries. |

```ts
authors: f.refs('Authors', { to: 'authors', max: 3 }),
```
