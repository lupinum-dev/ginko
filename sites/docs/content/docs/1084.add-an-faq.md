This recipe adds a page of questions and answers to a site that runs and was made from a template, for example the `starter` of the [Quick start]($docs.getting-started). At the end, `/faq` shows the questions as an accordion, followed by a line that leads to your contact page, and search engines get the questions as FAQ data.

The templates `saas`, `events` and `local-business` have the finished feature. This recipe copies it from `saas`. For a site you built by hand, read the brick with `useGinko('faq')` in a page of your own; [Use ready-made bricks]($docs.ready-made-bricks) shows the brick.

## What you add

| Part | Where |
| --- | --- |
| Brick | `faq` from `@lupinum/ginko/basics`, in `ginko.config.ts` |
| Content | `content/faq/<n>.<name>.md` |
| Page | `app/pages/faq.vue` |
| Code | `app/components/block/Faq.vue` and the accordion in `app/components/ui/accordion/` |
| Texts | `i18n/faq/<language>.json` |

## Steps

::steps
#### Get the files

In your site's folder, create a copy of the template `saas` next to it, in the languages of your site. It needs no `npm install`:

```bash
npm create ginko@latest ../saas-files -- --template saas --locales en,de
```

#### Copy the FAQ into your site

```bash
cp ../saas-files/app/components/block/Faq.vue app/components/block/
cp -R ../saas-files/app/components/ui/accordion app/components/ui/
cp ../saas-files/app/pages/faq.vue app/pages/
cp -R ../saas-files/i18n/faq i18n/
```

#### Add the brick and the page

```ts [ginko.config.ts]
import { faq, legal, notices, site } from '@lupinum/ginko/basics'

export default defineSite({
  // …
  pages: {
    home: localized('/'),
    faq: localized('/faq'),
  },
  bricks: {
    // … the bricks you have
    faq: faq({ source: 'files' }),
  },
})
```

The page key must stay `faq`, because the page is `app/pages/faq.vue`. The questions have no pages of their own, so the brick has no route.

#### Write the questions

One file per question. The number sets the order:

```markdown [content/faq/1.rates.md]
---
question: How do you charge?
answer: By the word of the source text. You get a fixed quote before I start.
---
```

```markdown [content/faq/1.rates.de.md]
---
question: Wie rechnen Sie ab?
answer: Nach Wörtern des Ausgangstextes. Vor dem Start bekommen Sie ein festes Angebot.
---
```

```markdown [content/faq/2.formats.md]
---
question: Which file formats do you take?
answer: Word, InDesign and PDF. For PDF the price is a little higher.
---
```

The answer is plain text: line breaks stay, Markdown does not. A question without a translation shows in the main language on the pages of the other languages.

#### Put the FAQ into the menu or the footer

```ts [app/app.config.ts]
footer: [{ page: 'faq', label: { en: 'Questions', de: 'Fragen' } }],
```
::

## Check that it works

- Open `http://localhost:3000/faq`. It shows "Questions and answers" and both questions. Click one: its answer opens.
- Below the questions, a line leads to the page `pages/contact`. Without that page, it shows the email and phone of `content/site.md`.
- Open `http://localhost:3000/de/faq`. It shows the German question first.
- Run `npm run check`. It prints `OK: schema and links are fine.`

Then delete the folder `../saas-files`.

## Show some questions on another page

`BlockFaq` shows questions as an accordion inside a section. The home page of the template `events` shows the first three. In `app/pages/index.vue`, read the brick in `<script setup>`:

```ts
const questions = useGinko('faq')
```

and add a section to the template:

```vue
<BlockSection title="Questions" :side="false">
  <BlockFaq :items="questions.items.slice(0, 3).map((item) => ({ id: item.id, question: item.data.question, answer: item.data.answer }))" />
</BlockSection>
```

The page `/faq` already gives search engines the data of all questions, so the home page needs none.

## Change it

The title and the lead of the page are in `i18n/faq/<language>.json`. To change them, set `faq.title` and `faq.lead` in your `i18n/<language>.json`: `{ "faq": { "title": "FAQ" } }`.
