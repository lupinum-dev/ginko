Diese Anleitung macht aus gespeicherten Werten Text, den ein Besucher liest: „€12.50“ und „October 8, 2026“ auf Englisch, „12,50 €“ und „8. Oktober 2026“ auf Deutsch. Am Ende folgen Preise und Daten der Sprache der Seite.

## Einen Preis zeigen

Ein Geldfeld enthält `{ amount, currency }`, mit dem Betrag in der kleinsten Einheit. `formatMoney` macht daraus Text. Importiere es aus `@lupinum/ginko`:

```vue
<script setup lang="ts">
import { formatMoney } from '@lupinum/ginko'

const prices = useGinko('prices')
const { language } = useI18n()
</script>

<template>
  <ul>
    <li v-for="item in prices.items" :key="item.id">
      {{ item.data.title }}: {{ formatMoney(item.data.price, language) }}
    </li>
  </ul>
</template>
```

`language` ist das Sprach-Tag der Seite, zum Beispiel `en` oder `de-AT`. Das Ergebnis folgt ihm:

| Aufruf | Ergebnis |
| --- | --- |
| `formatMoney({ amount: 1250, currency: 'EUR' }, 'en')` | `€12.50` |
| `formatMoney({ amount: 1250, currency: 'EUR' }, 'de')` | `12,50 €` |
| `formatMoney({ amount: 1250, currency: 'CHF' }, 'de-CH')` | `CHF 12.50` |
| `formatMoney({ amount: 39000, currency: 'EUR' }, 'en', { wholeWithoutMinor: true })` | `€390` |

Jedes Leerzeichen im Ergebnis ist ein geschütztes Leerzeichen. So bricht ein Preis nie in die nächste Zeile um.

## Ein Datum zeigen

Ein Datumsfeld enthält einen Text wie `2026-10-08`. `useI18n` hat ein Objekt `format`, das ihn in der Sprache der Seite schreibt:

```vue
<script setup lang="ts">
const { format } = useI18n()
</script>

<template>
  <time datetime="2026-10-08">{{ format.date('2026-10-08') }}</time>
</template>
```

| Aufruf | Englisch | Deutsch |
| --- | --- | --- |
| `format.date('2026-10-08')` | October 8, 2026 | 8. Oktober 2026 |
| `format.date('2026-10-08', 'short')` | 10/8/26 | 08.10.26 |
| `format.range('2026-06-20', '2026-06-21')` | June 20–21, 2026 | 20.–21. Juni 2026 |

Das zweite Argument von `format.date` ist `'short'`, `'medium'`, `'long'` (der Standard) oder `'full'`. Server und Browser schreiben denselben Text.

## Zeigen, was heute gilt

`useGinkoToday` liefert das heutige Datum als `YYYY-MM-DD`, in der Zeitzone der Seite:

```vue
<script setup lang="ts">
const route = useRoute()
const post = useGinkoEntry('news', () => route.params.slug)
const today = useGinkoToday()
const isToday = computed(() => post.value.data.date === today.value)
</script>

<template>
  <p v-if="isToday">Dieser Beitrag ist von heute.</p>
</template>
```

Der Wert rückt nach Mitternacht weiter, ohne dass die Seite neu lädt. Vergleiche mit ihm und nicht mit `new Date()`: Der Rechner des Besuchers kann in einer anderen Zeitzone stehen als die Seite.
