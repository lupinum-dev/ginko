AI agents read Markdown better than HTML. A Ginko site serves both from the same content, with no extra work. This guide shows what agents get, how to describe the site to them, and how to turn it off.

## What every site serves

| Address | Content |
| --- | --- |
| `<page>.md` | One entry as Markdown: `/news/opening.md` is the page `/news/opening`. |
| `/llms.txt` | The name of the site, a description, and a list of its entries with links to their Markdown. |
| `/llms-full.txt` | The text of all these entries in one file. |

An entry has a Markdown address when its brick has a route. The lists hold the entries of the main language.

## Steps

::steps
#### Describe the site for agents

```ts [ginko.config.ts]
export default defineSite({
  // …
  agents: { description: 'News and prices of the Linden Inn.' },
})
```

Without it, `llms.txt` shows `seo.description`.

#### Check the result

```bash
curl https://www.linde.example/llms.txt
```

```markdown
# Linden Inn

> News and prices of the Linden Inn.

## News

- [We are open](https://www.linde.example/news/opening.md)
```

Then ask for one entry:

```bash
curl -i https://www.linde.example/news/opening.md
```

The answer has `content-type: text/markdown` and the text of the entry.
::

## How an agent finds the Markdown

The HTML page names its Markdown version in a header:

```text
link: </news/opening.md>; rel="alternate"; type="text/markdown"
```

The normal address always answers with HTML, whatever the request asks for. Only the address with `.md` answers with Markdown. A host cache keeps one version per address, so this keeps visitors and agents apart.

A Markdown address without an entry answers with 404, also in Markdown, and suggests similar pages.

## Turn it off

```ts [ginko.config.ts]
agents: { enabled: false },
```

`/llms.txt`, `/llms-full.txt` and every `.md` address then answer with 404, and the pages have no `link` header.

## Your own file

A file `public/llms.txt` replaces the generated one. The same holds for `public/robots.txt`.

## Agents that write

On the platform, an agent with a key can also write content. With `agents: { review: true }`, everything such an agent writes waits for a yes from an owner. [Platform and CLI]($docs.platform-and-cli) explains it.
