This guide builds a language switch: a set of links that lead from a page to the same page in each other language. At the end, the switch on an entry leads to the translated entry, also when its address differs per language.

Every template has a switch. Build your own when you start without a template, or when you want another form.

## Steps

::steps
#### Read the alternates

`useI18n` returns `alternates`: the current page in every language of the site.

```vue [app/components/LanguageSwitch.vue]
<script setup lang="ts">
const { alternates } = useI18n()
</script>

<template>
  <nav aria-label="Language">
    <NuxtLink
      v-for="a in alternates"
      :key="a.code"
      :to="a.path"
      :hreflang="a.language"
      :aria-current="a.current ? 'page' : undefined"
    >
      {{ a.name }}
    </NuxtLink>
  </nav>
</template>
```

Each alternate has these values:

| Value | Meaning |
| --- | --- |
| `code` | The code of the language, such as `de` |
| `language` | Its language tag, such as `de-AT` |
| `name` | Its name in the language itself, such as "Deutsch" |
| `path` | The address of the current page in that language |
| `current` | `true` for the language of the current page |
| `translated` | `false` when the page has no version in that language |

#### Put it into the layout

```vue [app/app.vue]
<template>
  <LanguageSwitch />
  <NuxtPage />
</template>
```

#### Check the result

1. On a fixed page with translated paths, the switch leads from `/about` to `/de/ueber-uns`.
2. On an entry, it leads to the entry in the other language, such as `/de/neuigkeiten/wir-haben-geoeffnet`.
::

## A page without a translation

When the current page has no version in a language, `translated` is `false` and `path` is the start page of that language. Say so, or hide the link:

```vue
<NuxtLink v-for="a in alternates" :key="a.code" :to="a.path" :hreflang="a.language">
  {{ a.name }}<span v-if="!a.translated"> (start page)</span>
</NuxtLink>
```

## What you get without code

The links between languages for search engines (`hreflang`) and the `lang` attribute of the page come from the same data. You write nothing for them.
